# Feature: exp01 有限尺寸相图

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

由 S01（`L=8` 参数网格基态）计算归一化拓扑反映量 `~Z_R` 网格，
产出 D01（数据集 + 无标记相图裸图），并以 D01 裸图为底图叠加三对起点 /
终点标记与演化方向箭头，得起点终点标记示意图（D05）。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 输入：S01 网格每点的基态波函数 `ψ0`（`256` 分量，基矢约定见 S01 manifest，
  `PRE-001`）。
- 子系统取法（见 `docs/theory/topological_op.md`，`PRE-003`）：`L=8` 取中间
  `2n=4` 格点为 `I`（即格点 `3,4,5,6`），左右连续块 `I1=(3,4)`、`I2=(5,6)`
  各 `n=2` 比特；`R_I` 为中央键镜像交换。
- 观测量：`Z_R = Tr(ρ_I R_I)`，
  `~Z_R = Z_R / sqrt([Tr(ρ_I1^2) + Tr(ρ_I2^2)] / 2)`，
  其中 `ρ_I` 为 `ψ0` 在 `I` 上的约化密度矩阵，`ρ_I1`、`ρ_I2` 类推。
- 网格：与 S01 同网格（`s = i/100`、`δ = j/50`，`i,j = 1,…,99`），逐点计算，
  不插值、不平滑（`PRE-002`）。
- 简并点处理：对 S01 manifest 简并点表中 `404` 点不做特殊处理，统一使用
  S01 存储的 `ψ0` 计算（S01 规则：保留求解器最低本征矢，交下游解释）；
  D01 数据集须逐点携带简并标记（继承自 S01），以便下游判断
  （`POST-002`）。
- 标记（`PRE-004`）：三对起点 / 终点，每对同相，配对固定——
  平庸对 `(0.01,0.02) → (0.21,0.42)`（`~Z_R ≈ 0.996`）、
  拓扑对 `(0.99,0.02) → (0.90,0.20)`（`~Z_R ≈ −0.98`）、
  AFM 对 `(0.50,1.98) → (0.61,1.44)`（`~Z_R ≈ 0.009`）；
  终点均为 D01 落定后在其起点同相连通区相深处选取的网格点。
  三对各用一色区分；起点沿用圆点样式三色；终点 marker 形状与颜色均区别于起点；
  每对起点→终点画演化方向箭头。
- D05 由 D01 裸图叠加上述标记与箭头得到；出图实现本身由实现层安排，
  不属实验定义。

### 3. Outputs

- D01：`~Z_R[99,99]`（与 S01 同坐标 ordering），附参数元数据 `(s,δ,L)`；
  无标记相图裸图（与数据集同坐标系）。
- D05：D01 裸图底图 + 三对标记与配对箭头叠加；三对坐标与配对关系、
  颜色区分存档。
- 来源标注：输入 S01 的 schema（`shared01/v1`）与 manifest 标识；
  每点简并标记。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II
（`POST-001`–`POST-004`）。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D01：S01 网格上每点的 `~Z_R` 值（与 S01 同网格、`99×99` 点），
  含数据集与无标记相图裸图。
- `BND-002` D05：D01 裸图底图 + 三对标记与配对箭头叠加。

#### Out of Scope

- `BND-003` S01 基态生产（shared-01，保持开放引用，不封盘）。
- `BND-004` `S(q)`、`S(π)`、string、`Q` 热力图（exp02）。
- `BND-005` 能隙标度（exp03 自含 `L=8,12,16`）。
- `BND-006` VQE、真机测量与读出缓解（exp04–exp06）。
- `BND-007` 拟设结构示意图 D06（exp04，纯示意，无数据依赖）。

#### Dependencies

- `DEP-001` S01：`data/shared01/`（schema `shared01/v1`），基态波函数 +
  能量 + 简并点表。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `ρ_I` / `ρ_I1` / `ρ_I2`：`ψ0` 在 `I=(3,4,5,6)` / `I1=(3,4)` / `I2=(5,6)`
  上的约化密度矩阵。
- `R_I`：中央键镜像交换。
- `Z_R = Tr(ρ_I R_I)`；`~Z_R = Z_R / sqrt([Tr(ρ_I1^2) + Tr(ρ_I2^2)] / 2)`。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 输入：S01 网格每点的基态波函数 `ψ0`（`256` 分量）；
  S01 文件存在、schema 为 `shared01/v1`、基矢约定字符串与预期一致，
  否则拒绝执行。
- `PRE-002` 网格：与 S01 同网格（`s = i/100`、`δ = j/50`，
  `i,j = 1,…,99`），逐点计算，不插值、不平滑。
- `PRE-003` 子系统取法：`I=(3,4,5,6)`，`I1=(3,4)`，`I2=(5,6)`；
  `R_I` 为中央键镜像交换。
- `PRE-004` D05 三对标记：平庸对 `(0.01,0.02) → (0.21,0.42)`、
  拓扑对 `(0.99,0.02) → (0.90,0.20)`、
  AFM 对 `(0.50,1.98) → (0.61,1.44)`；每对同相，配对固定；
  三对各用一色区分；起点圆点样式三色；终点 marker 形状与颜色均区别于起点；
  每对起点→终点画演化方向箭头。

### D. Postconditions

定义一次成功计算完成后必须成立的条件（除注明外，均按网格点计）。

- `POST-001` D01：`~Z_R[99,99]`（与 S01 同坐标 ordering），附参数元数据
  `(s,δ,L)`；无标记相图裸图（与数据集同坐标系）。
- `POST-002` 简并点：S01 manifest 简并点表 `404` 点不做特殊处理
  （统一用 S01 存储的 `ψ0`）；D01 数据集逐点携带简并标记（继承自 S01）。
- `POST-003` D05：D01 裸图底图 + 三对标记与配对箭头叠加；
  三对坐标与配对关系、颜色区分存档。
- `POST-004` 来源标注：输入 S01 的 schema（`shared01/v1`）与 manifest 标识；
  每点简并标记；具体落盘格式与存储路径由 plan 确定；
  须保证出图可按 `(s,δ)` 检索。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 每点 `ρ_I` 迹为 `1`（`|Trρ − 1| < 1e-10`）、厄米半正定
  （最小本征值 `> −1e-10`）；归一化分母非零有限（`> 1e-12`）。
- `INV-002` D01 无缺失、无 NaN；网格坐标与 S01 逐点一致。
- `INV-003` D05 底图与 D01 坐标系一致。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `INV-001`、`INV-002`、`POST-002`：逐点
  `|Trρ − 1| < 1e-10`、`ρ` 最小本征值 `> −1e-10`、
  分母 `> 1e-12` 且有限；无缺失、无 NaN；简并标记与 S01 manifest 逐点一致。
- `VAL-002` → verifies `POST-003`、`INV-003`、`PRE-004`：D05 底图坐标系
  与 D01 一致（脚本自检断言）；三对标记坐标 / 配对一致；
  每对一起点一终点一箭头，无多标、无漏标。
- `VAL-003` → verifies `PRE-001`：S01 输入门控（缺失 / schema 不符 /
  基矢约定不符均拒绝）。
- `VAL-004`（诊断，只记录）：`~Z_R` 全网格分布摘要（最小 / 最大 / 分位数），
  供相图解释参考。`δ` 大（Ising 偏）区与 `s→0` 区 `~Z_R` 的定性行为
  由相图解释，归下游判断，本 feature 只保证计算正确性。
- `VAL-005`（invalid-run）→ verifies `PRE-001`、`INV-001`、`POST-002`、
  `INV-003`、`PRE-004`：S01 输入缺失或 schema 不符；任一点 `ρ_I` 迹偏离
  `1` 超出阈值；简并标记丢失；D05 底图与 D01 坐标系不一致；
  D05 标记坐标 / 配对不符——出现任一情况该点（或整批）判 invalid，
  不得静默出图。
