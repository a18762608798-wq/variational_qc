# Feature: exp02 拓扑物理量

## 1. 目标

由 S01 / S02 基态计算轻采样物理量与归一化量，产出 D03（三相代表点 `S(q)` 曲线，
三条同图）与 D04（`S(π)` / string / `Q` / `~Z_R` 四联热力图）。
本 feature 只生产 D03、D04，不负责其他观测量与实验。

## 2. 边界

负责：

- D03：S02 三个代表点各自的 `S(q)` 曲线（同 q 网格、三条同图数据）。
- D04：S01 网格上每点的 `S(π)`、string、`Q`、`~Z_R`（四幅热力图数据，
  `(a)–(d)` 分块见 paper-outline）。

不负责：

- S01 / S02 基态生产（shared-01，保持开放引用）。
- D01 / D05 相图（exp01，保持开放引用；D04(d) 与 D01 独立重算，
  不消费 exp01 输出，事后可比对一致性）。
- 能隙标度（exp03）、VQE 与真机（exp04–exp06）、拟设示意图 D06（exp04）。

依赖：

- S01：`data/shared01/`（schema `shared01/v1`），基态波函数 + 简并点表。
- S02：三代表点坐标（S01 网格子集，见 S01 manifest；代表点波函数即 S01 同坐标条目）。

## 3. 实验 / 计算定义

- 输入：S01 网格每点基态波函数 `ψ0`（`256` 分量，基矢约定见 S01 manifest）；
  D03 取其中 S02 三坐标条目。
- 结构因子（见 `doc/theory/topological_op.md`）：
  `S(q) = (1/L) Σ_{i,j} e^{iq(i−j)} <Z_i Z_j>`，`L=8`，期望取自 `ψ0`。
- D03 q 网格：`q = 2πk/100`（`k = 1,…,99`），即 `[0,2π]` 作 101 点均匀划分后去边界，
  共 99 点，显含 `q=π`（`k=50`）；三代表点共用此网格。
- D04 网格：与 S01 同网格（`s = i/100`、`δ = j/50`，`i,j = 1,…,99`），逐点计算，
  不插值、不平滑。
- D04 各量（定义见 `doc/theory/topological_op.md`）：
  - (a) `S(π)`：上式取 `q=π`；
  - (b) string：`O_str(d=L/2−1=3)`；
  - (c) `Q = 4/3 + 2 O_str − S(π)/6`；
  - (d) `~Z_R`：与 exp01 同定义（`I=(3,4,5,6)` 等）独立重算。
- 简并点处理：与 exp01 同规则——统一使用 S01 存储的 `ψ0`，不做特殊处理；
  输出数据集逐点携带简并标记（继承自 S01）。
- D04 四联版式为 `(a) S(π)` / `(b) string` / `(c) Q` / `(d) ~Z_R`；
  出图实现本身由实现层安排，不属实验定义。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- D03：q 网格 + 三代表点 `S(q)` 曲线（附相标签 trivial / topo / AFM 与代表点坐标）。
- D04：四联热力图数据（`S(π)`、`O_str`、`Q`、`~Z_R` 各 `99×99`，与 S01 同坐标 ordering），
  附参数元数据 `(s,δ,L)`。
- 来源标注：输入 S01 的 schema 与 manifest 标识；每点简并标记。
- 具体落盘格式与存储路径由 plan 确定；须保证出图可按 `(s,δ)`（D04）与按 q（D03）检索。

## 5. 验证

- 正确性条件：`S(q) ≥ 0`（功率谱非负）；D04(a) 每点等于 D03 同代表点 `q=π` 处取值
  （D03↔D04 内洽，代表点重合处必一致）；`Q` 与 (a)(b) 满足线性组合恒等式；
  无缺失、无 NaN；网格坐标与 S01 逐点一致。
- 收敛 / 稳定性要求：本 feature 无迭代求解，不适用收敛判据；
  数值精度以双精度计算极限为准（具体阈值由 plan 定）。
- 参考解 / benchmark：`S(π)` 作 AFM 标签的解释归论文正文，本 feature 只保证计算正确性。
- invalid run 判据：S01 输入缺失或 schema 不符；D03↔D04 代表点 `S(π)` 内洽不符；
  `Q` 恒等式不符；简并标记丢失——出现任一情况相关点（或整批）判 invalid，
  不得静默出图。
