# Implementation Plan: exp03 附录能隙

## 1. 实现思路

- 主要模块：`SectorBasis`（`P=−2` 扇区轨道基矢 + 扇区矩阵组装）、
  `GapSolver`（逐点扇区对角化取最低两本征值 → `Δ`）、
  `CrossFit`（交点 bracketing + 线性插值、最小二乘拟合）、
  `Store`（按 `L` 分块增量落盘 + 断点续算 + D02a/b/c 组装）、
  薄编排 `scripts/run_exp03.jl`、生产断言 `scripts/verify_exp03.jl`、
  出图 `scripts/plot_D02.py`（三独立图 `(a)=D02a` / `(b)=D02b` / `(c)=D02c`）。
- 数据流：无外部输入（自含）→ 每 `(L,s)` 稀疏组装扇区 `H` → ARPACK 最低两根 →
  `Δ_sec` → 分块落盘 → 组装 `(i)(ii)` + `(iii)` 另两点（`L=20/24` 单点直算，
  同残差门控）→ 交点/拟合（拟合仅用 `20/24`）→ Python 出图。
- 核心算法：显式构造 `P=−2` 轨道基（`Z_tot=0` 比特串在
  `{I, X̄, R, X̄R}` 下全 `+` 对称化，`X̄=∏X` 为全比特翻转，
  `R` 为比特序反转），`H` 键项直接作用于比特串组装扇区矩阵为稀疏三元组
  （`SparseMatrixCSC`：对角 + 每键至多一项非对角，`nnz`/行 `~O(键数)`）；
  扇区维数 `23/252/3299`（`L=8/12/16`），最低两本征对经 ARPACK
  （`eigs`, `nev=2`, `which=:SR`, `tol=1e-12`）求得，逐点残差硬断言
  `< 1e-10`；`L=16` 单点约 `0.09s`。
- 关键技术选择：不用全空间稠密 `H`（`L=16` 时 `65536²` 不可行，
  故不复用 `build_hamiltonian`，只复用其键集/权重/基矢约定语义）；
  不用稠密全谱对角化（实测 `L=16` 单点 `115s`，`3×194` 点不可行，
  改稀疏 ARPACK 后单点 `0.09s`，见 §5）；
  不用迭代法之外的收敛参数（ARPACK `tol` 为求解器精度，由残差断言锁定）；
  不用惩罚 `H'` 法（显式基矢构造性保证扇区纯度，无需 `λ` 选择与事后验证）；
  数值全部在 Julia，出图全部在 Python，以 `.npz` 为界，Python 不重算任何物理量。

以上均为实现层选择；`L` 取值、能隙定义、网格、交点规则、拟合方法、
输出内容与验证条件沿用 spec，未改动实验语义。

## 3. 数值与技术决策

- 数值方法：扇区矩阵稀疏三元组组装 + ARPACK 求最低两本征对
  （`ComplexF64`，`L=16` 扇区 `3299` 维、`nnz ~ 5×10^4`，单点约 `0.1s`，
  含基矢枚举与组装）；交点线性插值、拟合最小二乘均为闭式代数，无近似。
  理由：键项每行至多 `O(键数)` 非零，Krylov 法取两根毫秒级；
  稠密全谱实测 `115s`/点（干净态单线程），`582` 点不可行。
- 精度：硬断言阈值 `Δ ≥ −1e-12`（roundoff 容限，spec `Δ≥0` 的实现落实）、
  逐点本征对残差 `‖Hv−λv‖ < 1e-10`（生产门控，失败即 invalid；
  残差直接锁定所求两根，比全矩阵厄米范数更强且为 `O(nnz)`）、
  ARPACK `tol=1e-12`（求解器精度，由残差断言锁定）、拟合重算 `(a,b)`
  一致 `< 1e-12`（拟合仅用 `L=20/24` 两点，由该两点重算）、
  `L=8` 与全空间暴力（`build_hamiltonian` + `P` 投影）最低两根一致 `< 1e-10`
  （测试层）、`L=16` 单点与稠密全谱一致 `< 1e-8`
  （测试层，一次性约 2 分钟）；
  `L=20/24` 单点走同 `solve_gap` 路径、同残差门控（实测 `L=24` 单点约 2 分钟），
  资源守卫 `MAX_L` 由 `20` 放宽至 `26`（枚举 `O(2^L)` 的实现层护栏，不属实验定义）。
  以上变更只换求解路径，不改观测量定义与输出内容（spec §5 求解器判据本就授权 plan 定）。
- 并行：`Threads.@threads` 遍历点表，`BLAS.set_num_threads(1)`（宪法 V）；
  唯 `eigs` 调用经模块锁串行（ARPACK Fortran 内部状态非线程安全，
  多线程并发调 `eigs` 实测触发 `XYAUPD info=3` / 段错误；组装与残差检查保持并行）。
- 增量落盘（宪法 IV）：按 `L` 分块即算即存 + 完成表续算，组装为纯拼接；
  预计总量共 `582` 点，约数分钟，中断可恢复；
  生产顺序按 `L=8`、`12`、`16`，先在小尺寸验证全链路再跑 `L=16`；
  `(iii)` 另两点（`L=20/24`）经独立 `extra_iii` chunk 落盘 + 进度位续算后并入组装。
- 出图：matplotlib + `figure_style.py`，只读 D02a/b/c 与版式元数据。
- 关键依赖：Julia `LinearAlgebra` + `SparseArrays`（stdlib）、`Arpack.jl`、
  `NPZ.jl`、`JSON3.jl`（`Project`/`Manifest` 已更新并冻结）；
  Python 侧沿用 CondaPkg（numpy + matplotlib，现成）。

## 4. 验证方案

spec 验证条件的落实（硬断言，失败即 invalid）：

- 扇区纯度（构造层 + 测试层）：基矢代表元逐个 `popcount == L/2`；
  随机扇区矢量在 `X̄`、`R` 下不变；`L=8` 全点扇区结果与全空间暴力一致。
- 逐点：`Δ ≥ −1e-12`；本征对残差 `< 1e-10`（`nconv ≥ 2` 否则抛错）；
  无缺失、无 NaN。
- 组装：交点每对至少一个 bracketing（否则 invalid，不静默出图）；
  拟合 `(a,b)` 由存档 `L=20/24` 两点重算一致；(iii) 中 `L=8/12/16` 三点
  与 (i) `s=0.5` 条目一致（同一计算复用，构造性保证，断言锁定）。
- 出图：三独立图顺序 `(a)=D02a` / `(b)=D02b` / `(c)=D02c` 与版式一致；交点 marker 坐标与存档交点表一致；
  `(c)` 五点 + 拟合线（`20/24`）与存档一致；
  底图坐标系与 D02a/b/c 数据一致（脚本自检断言）。
- 单元测试：轨道基构造性（维数 `>0`、代表元磁化、算符不变性）；
  `L=8` 暴力一致；`L=16` 单点稠密全谱抽查；插值/拟合合成数据（已知交点直线、
  共线三点精确恢复）；`sector_hamiltonian` 非法 `L` 拒绝路径；
  ARPACK 不收敛拒绝路径（`nconv < 2` 抛错）。

诊断量（只记录、不设通过阈值）：

- `b` 与 `0` 的偏离（相对 `a` 尺度记录）；每 `L` 最小 `Δ` 及位置；
  三对交点 `s` 值摘要（期待近 `0.5`，作论文解释证据，不作通过条件）。
