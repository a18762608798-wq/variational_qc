# Feature: exp03 附录能隙

## 1. 目标

自含计算 `L=8,12,16` 对称性能隙，产出 D02a（`δ=0` 能隙曲线）、D02b（`s` vs `A`
交点）、D02c（`Δ` vs `1/L` 线性拟合）三部分数据 + 附录图。
本 feature 只生产 D02a/b/c，不负责其他观测量与实验。

## 2. 边界

负责：

- D02a/b/c：(i) `δ=0` 时三个 `L` 的对称能隙 `Δ_sec(s)` 曲线数据（→D02a）；
  (ii) `A=Δ·L` 的 `s` vs `A` 数据（`s ∈ [0.45,0.6]`）及曲线交点标记（→D02b）；
  (iii) `(δ=0,s=0.5)` 处 `L ∈ {8,12,16,20,24}` 五点的 `Δ` vs `1/L` 数据
  （五点全画），线性拟合仅用其中 `L=20,24` 两点（→D02c）。

不负责：

- S01 / S02 基态与 D01 / D03 / D04 / D05（shared-01、exp01、exp02，
  保持开放引用，不消费；`L=8` 即使尺寸相同也独立重算，
  因本实验量为对称扇区能隙而非全空间基态）。
- 能隙之外的任何观测量；VQE、真机测量与读出缓解（exp04–exp06）；
  拟设结构示意图 D06（exp04）。

依赖：

- 无外部数据依赖（自含；模型与对称性定义见 `doc/theory/H.md`，
  能隙定义见 `doc/theory/gap.md`）。

## 3. 实验 / 计算定义

- 系统 / 模型：SSH XXZ 链，OBC，`L ∈ {8,12,16}`，
  哈密顿量 `H(s,δ)` 定义见 `doc/theory/H.md`。
- 能隙：对称性能隙 `Δ_sec(L,s) = E1^{(P=-2)} − E0^{(P=-2)}`
  （见 `doc/theory/gap.md`），其中 `P` 定义与扇区筛选
  （`H'=H+P`）见 `doc/theory/H.md`；
  `P=−2 ⇔ Z_tot=0、∏X=+1、R=+1`（由 `P` 定义直接得出）。
- `δ` 固定：三部分均取 `δ=0`（Heisenberg 各向同性点；
  其中 (ii) 的 `δ=0` 已由 `paper-outline.md` 明确）。
- `s` 网格（与 S01 同约定：区间作 101 点均匀划分后去边界，共 99 点）：
  (i) `s ∈ [0,1]`，`s=i/100`（`i=1,…,99`）；
  (ii) `s ∈ [0.45,0.6]`，`s=0.45+0.15k/100`（`k=1,…,99`）；
  (ii) 中各 `L` 须共用同一 `s` 网格（交点可比）。
- (ii)：`A(L,s) = Δ_sec(L,s)·L`；标记两两曲线交点
  （`8–12`、`8–16`、`12–16`），交点 `s` 坐标以前后相邻两点线性插值确定。
- (iii)：取点 `(δ=0,s=0.5)`，`L ∈ {8,12,16,20,24}`，横轴 `1/L`，纵轴 `Δ`，
  五点全画；其中 `L=8/12/16` 复用 (i) 同点值，不另算，`L=20/24` 独立计算
  （同扇区求解路径、同残差门控）；
  线性拟合仅用 `L=20,24` 两点（两点定直线），`Δ = a·(1/L)+b`，
  报告拟合系数 `a、b`
  （理论期待 `b=0`，见 `doc/theory/gap.md` 有限尺寸标度一节）；
  拟合方法为最小二乘。
- `L→∞` 交点趋于 `s=0.5` 系论文解释，不属计算定义。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- D02a/b/c 数据：(i) `Δ_sec` 网格（→D02a）、(ii) `A` 网格（→D02b）、(iii) 五点 `(1/L,Δ)` +
  拟合系数 `(a,b)`（拟合仅用其中 `L=20,24` 两点，→D02c）；每点附参数元数据 `(L,s,δ)`。
- D02a/b/c 图：附录能隙图（三部分各独立成图；版式由实现层安排，不属实验定义）。
- 具体落盘格式与存储路径由 plan 确定；须保证可按 `(L,s)` 检索。

## 5. 验证

- 正确性条件：`Δ_sec ≥ 0`；`A` 有限；拟合系数与 (iii) 拟合子集
  （`L=20,24` 两点）数据自洽（由数据重算 `a、b` 一致）；无缺失、无 NaN。
- 收敛 / 稳定性要求：扇区最低两本征值须收敛至求解器精度；
  具体判据与阈值由 plan 定。
- 参考解 / benchmark：`b≈0` 作有限尺寸标度定性期待（见 `doc/theory/gap.md`），
  数值容差由 plan 定，不作本 spec 硬阈值。
- invalid run 判据：求解未限定 `P=−2` 扇区；任一点缺失 / NaN；
  (ii) 各 `L` 网格不一致；拟合系数与 (iii) 数据不一致——
  出现任一情况相关点（或整批）判 invalid，不得静默出图。
