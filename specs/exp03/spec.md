# Feature: exp03 附录能隙

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

自含计算 `L=8,12,16` 对称性能隙，产出 D02a（`δ=0` 能隙曲线）、D02b（`s` vs `A`
交点）、D02c（`Δ` vs `1/L` 线性拟合）三部分数据 + 附录图。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 系统 / 模型：SSH XXZ 链，OBC，`L ∈ {8,12,16}`，
  哈密顿量 `H(s,δ)` 定义见 `doc/theory/H.md`（`PRE-001`）。
- 能隙：对称性能隙 `Δ_sec(L,s) = E1^{(P=-2)} − E0^{(P=-2)}`
  （见 `doc/theory/gap.md`），其中 `P` 定义与扇区筛选
  （`H'=H+P`）见 `doc/theory/H.md`；
  `P=−2 ⇔ Z_tot=0、∏X=+1、R=+1`（由 `P` 定义直接得出）。
- `δ` 固定：三部分均取 `δ=0`（Heisenberg 各向同性点；
  其中 (ii) 的 `δ=0` 已由 `paper-outline.md` 明确，`PRE-001`）。
- `s` 网格（与 S01 同约定：区间作 101 点均匀划分后去边界，共 99 点，
  `PRE-002`）：
  (i) `s ∈ [0,1]`，`s=i/100`（`i=1,…,99`）；
  (ii) `s ∈ [0.45,0.6]`，`s=0.45+0.15k/100`（`k=1,…,99`）；
  (ii) 中各 `L` 须共用同一 `s` 网格（交点可比）。
- (ii)（`PRE-003`）：`A(L,s) = Δ_sec(L,s)·L`；标记两两曲线交点
  （`8–12`、`8–16`、`12–16`），交点 `s` 坐标以前后相邻两点线性插值确定。
- (iii)（`PRE-004`）：取点 `(δ=0,s=0.5)`，`L ∈ {8,12,16,20,24}`，
  横轴 `1/L`，纵轴 `Δ`，五点全画；其中 `L=8/12/16` 复用 (i) 同点值，
  不另算，`L=20/24` 独立计算（同扇区求解路径、同残差门控）；
  线性拟合仅用 `L=20,24` 两点（两点定直线），`Δ = a·(1/L)+b`，
  报告拟合系数 `a、b`（理论期待 `b=0`，见 `doc/theory/gap.md`
  有限尺寸标度一节）；拟合方法为最小二乘。
- `L→∞` 交点趋于 `s=0.5` 系论文解释，不属计算定义（`VAL-004` 备注）。

### 3. Outputs

- D02a/b/c 数据：(i) `Δ_sec` 网格（→D02a）、(ii) `A` 网格（→D02b）、
  (iii) 五点 `(1/L,Δ)` + 拟合系数 `(a,b)`（拟合仅用其中 `L=20,24` 两点，
  →D02c）；每点附参数元数据 `(L,s,δ)`（`POST-001`）。
- D02a/b/c 图：附录能隙图（三部分各独立成图；版式由实现层安排，
  不属实验定义，`POST-002`）。
- 具体落盘格式与存储路径由 plan 确定；须保证可按 `(L,s)` 检索
  （`POST-003`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D02a/b/c：(i) `δ=0` 时三个 `L` 的对称能隙 `Δ_sec(s)` 曲线数据
  （→D02a）；(ii) `A=Δ·L` 的 `s` vs `A` 数据（`s ∈ [0.45,0.6]`）及曲线交点标记
  （→D02b）；(iii) `(δ=0,s=0.5)` 处 `L ∈ {8,12,16,20,24}` 五点的 `Δ` vs `1/L`
  数据（五点全画），线性拟合仅用其中 `L=20,24` 两点（→D02c）。

#### Out of Scope

- `BND-002` S01 / S02 基态与 D01 / D03 / D04 / D05（shared-01、exp01、exp02，
  保持开放引用，不消费；`L=8` 即使尺寸相同也独立重算，
  因本实验量为对称扇区能隙而非全空间基态）。
- `BND-003` 能隙之外的任何观测量；VQE、真机测量与读出缓解（exp04–exp06）；
  拟设结构示意图 D06（exp04）。

#### Dependencies

- `DEP-001` 无外部数据依赖（自含；模型与对称性定义见 `doc/theory/H.md`，
  能隙定义见 `doc/theory/gap.md`）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `Δ_sec(L,s) = E1^{(P=-2)} − E0^{(P=-2)}`：对称性能隙。
- `P=−2 ⇔ Z_tot=0、∏X=+1、R=+1`。
- `A(L,s) = Δ_sec(L,s)·L`。
- 拟合直线 `Δ = a·(1/L)+b`。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 系统：SSH XXZ 链，OBC，主体 `L ∈ {8,12,16}`；
  三部分计算均取 `δ=0`。
- `PRE-002` `s` 网格（与 S01 同约定）：(i) `s ∈ [0,1]`，`s=i/100`
  （`i=1,…,99`）；(ii) `s ∈ [0.45,0.6]`，`s=0.45+0.15k/100`
  （`k=1,…,99`）；(ii) 中各 `L` 须共用同一 `s` 网格。
- `PRE-003` (ii) 交点：标记两两曲线交点（`8–12`、`8–16`、`12–16`），
  交点 `s` 坐标以前后相邻两点线性插值确定。
- `PRE-004` (iii)：取点 `(δ=0,s=0.5)`，`L ∈ {8,12,16,20,24}`，横轴 `1/L`，
  纵轴 `Δ`，五点全画；其中 `L=8/12/16` 复用 (i) 同点值，不另算，
  `L=20/24` 独立计算（同扇区求解路径、同残差门控）；线性拟合仅用
  `L=20,24` 两点（两点定直线），拟合方法为最小二乘，报告拟合系数 `a、b`。

### D. Postconditions

定义一次成功计算完成后必须成立的条件。

- `POST-001` D02a/b/c 数据：(i) `Δ_sec` 网格（→D02a）、(ii) `A` 网格
  （→D02b）、交点表、(iii) 五点 `(1/L,Δ)` + 拟合系数 `(a,b)`（→D02c）；
  每点附参数元数据 `(L,s,δ)`。
- `POST-002` D02a/b/c 图：附录能隙图，三部分各独立成图
  （版式由实现层安排，不属实验定义）。
- `POST-003` 具体落盘格式与存储路径由 plan 确定；须保证可按 `(L,s)` 检索。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 求解限定 `P=−2` 扇区。
- `INV-002` `Δ_sec ≥ 0`（数值容限 `Δ ≥ −1e-12`）；`A` 有限；
  拟合系数与 (iii) 拟合子集（`L=20,24` 两点）数据自洽
  （由数据重算 `a、b` 一致，`< 1e-12`）。
- `INV-003` 扇区最低两本征值须收敛至求解器精度
  （逐点本征对残差 `< 1e-10`；具体判据与阈值由 plan 定）。
- `INV-004` 无缺失、无 NaN。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `INV-002`：`Δ ≥ −1e-12`；拟合重算一致 `< 1e-12`；
  (iii) 与 (i) `s=0.5` 一致。
- `VAL-002` → verifies `INV-003`：逐点本征对残差 `< 1e-10`。
- `VAL-003` → verifies `POST-001`：每对交点至少一个 bracketing
  （否则 invalid，不静默出图）；交点表。
- `VAL-004`（诊断，只记录）：`b` 与 `0` 的偏离（相对 `a` 尺度记录，
  `b≈0` 为定性期待，不作硬阈值）；每 `L` 最小 `Δ` 及位置；
  三对交点 `s` 值摘要（期待近 `0.5`，作论文解释证据，不作通过条件）。
- `VAL-005`（invalid-run）→ verifies `INV-001`、`INV-004`、`PRE-002`、
  `INV-002`：求解未限定 `P=−2` 扇区；任一点缺失 / NaN；
  (ii) 各 `L` 网格不一致；拟合系数与 (iii) 数据不一致——
  出现任一情况相关点（或整批）判 invalid，不得静默出图。
