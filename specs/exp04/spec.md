# Feature: exp04 模拟机 VQE

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

在态矢量模拟机上沿两条 `δ` 线做 VQE，为真机对比提供模拟机底数，并产出拟设结构示意图。具体计算目标：

- S06（`p=1,2,3` 拟设电路的曲线结果，D08 模拟机图层底数）；
- S03（S06 的 `θ*` 视图，供 exp06 真机照抄消费）；
- D06a–c（三分相拟设结构示意图，纯示意，无数据）。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 系统 / 模型：SSH XXZ 链，OBC，`L=8`，哈密顿量 `H(s,δ)` 定义见
  `docs/theory/H.md`。
- 拟设：orbit 拟设，定义见 `docs/theory/ansatz.md`（轨道分组、每轨道
  `(θ,φ)`、`δ=0` 时 `θ=φ` 参数减半、子层顺序与初态配对、
  `U^{(l)}=U^{(l)}_S U^{(l)}_F`，`p=1,2,3`，参数量 `Nθ=Lp`（`δ≠0`）或
  `Lp/2`（`δ=0`））。
- 初态：三参考态见 `docs/theory/psi0.md`（平庸奇键单态 / 拓扑 bulk+首尾单态 /
  AFM GHZ），均为 `P=−2` 扇区；每点三初态各做一路优化，取综合最小
  （见 `docs/theory/cost_fun.md`：`C*(s*,δ*) = min_a min_θ C_a(θ)`，
  每路内可用多种子 restart，同样取最小）。
- 代价函数：`E(θ) = ⟨ψ(θ)|H(s,δ)|ψ(θ)⟩`（态矢量精确期望，无采样噪声、
  无硬件噪声；噪声模型归 exp06，不属本实验）。
- 两线网格（`PRE-001`）：`δ=0` 与 `δ=0.85`（D08 四面板的两线）；
  `s` 网格每线 99 点、去边界。
- 每点输出量：三路各自的 `θ*_a`、`E*_a` 取最小者为 `θ*`、`E*`
  （须同时存档获胜初态标签 `a*`），外加该最优态上的 `S(π)` 与 string 期望
  （`POST-001`）。
- 求解策略：`p=1` 时全局随机采样 + 局域 L-BFGS 精修；
  `p>1` 时同路链式 warm start（`PRE-003`）后再做局域 L-BFGS 精修至收敛；
  全局采样集须含零向量（`PRE-002`，恒等层对应初态本身）。
  收敛门与棘轮接受规则见 `INV-001`、`INV-002`。

### 3. Outputs

- S06：每 `(δ,s,p)` 点的最优结果曲线数据（三路全量 + 最小路 + 观测量）。
- S03：全网格 `594` 组最优参数（与 S06 同一 `θ*` 的两种视图，非两次计算）。
- D06a–c：三分相拟设结构示意图（版式由实现层安排）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II
（`POST-001`、`POST-005`、`POST-006`、`BND-003`）。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` S06：`δ=0` 与 `δ=0.85` 两条线上每点 `p=1,2,3` 的 VQE 结果曲线数据。
- `BND-002` S03：全网格最优参数（`2×99×3=594` 组 `θ*`），供 exp06 消费。
- `BND-003` D06a–c：三分相拟设结构示意图（trivial / topo / AFM，每相初态 +
  所需拟设电路；纯示意，无数据依赖；须如实反映 `docs/theory/ansatz.md`
  的轨道分组、奇偶子层与 `p` 层堆叠，不虚构门类型与连接）。

#### Out of Scope

- `BND-004` S01 / S02 基态与 D01–D05（shared-01、exp01、exp02，保持开放引用，
  不消费、不复算；三路取最小策略不引用 D01 相区）。
- `BND-005` 能隙标度（exp03）、真机优质比特与 S04（exp05）、真机测量与
  D08（exp06，含读出分配矩阵 S05 与读出误差缓解）。

#### Dependencies

- `DEP-001` 无外部数据依赖（自含）。三路取最小不引用 D01 相区，
  故无对 exp01 的读依赖。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `a ∈ {triv, topo, AFM}`：初态指标（优化路）。
- `θ*_a` / `E*_a`：`a` 路各自的最优参数 / 最优能量。
- `θ*` / `E*` / `a*`：三路综合最小的参数 / 能量 / 获胜初态标签。
- `p ∈ {1,2,3}`：拟设层数。
- `converged` / `stagnant`：收敛旗（严格收敛 / 棘轮接受，区分存档）。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 计算网格：`δ ∈ {0, 0.85}`；`s = i/100`，`i = 1..99`
  （去边界 99 点，与 S01 同约定）；`p ∈ {1,2,3}`。
- `PRE-002` 全局采样集须含零向量（恒等层对应初态本身，
  保证 `E* ≤ E(θ_init)` 构造性成立）。
- `PRE-003` `p>1` 同路链式 warm start：`p=2` 初值取同路 `p=1` 最优参数，
  `p=3` 取同路 `p=2` 最优参数；新增层参数初始化与采样数 / 收敛阈值由 plan 定。

### D. Postconditions

定义一次成功计算完成后必须成立的条件（除注明外，均按 `(δ,s,p)` 点计）。

- `POST-001` 每点存三路全量 `(θ*_a,E*_a)` 取最小者 `θ*`、`E*` + `a*` +
  该最优态的 `S(π)`、string 期望，每点附参数元数据 `(δ,s,p,L)`；
  S03 为全网格 `594` 组 `(δ,s,p,θ*,a*)`（须含 exp06 复现所需的初态 / 拟设标识，
  与 S06 同值引用非重算）；须保证可按 `(δ,s,p)` 检索，exp06 可按点取用；
  具体落盘格式与存储路径由 plan 确定。
- `POST-002` 每点 `E* ≤ E(θ_init)`（VQE 不劣于初态；数值容限由 plan 定）。
- `POST-003` 终态守恒量（`Z_tot`、`∏X`、`R`）与初态一致
  （拟设保对称；漂移阈值由 plan 定）。
- `POST-004` `δ=0` 时参数满足 `θ=φ` 约束（结构式参数化 `Nθ=Lp/2`，
  非事后约束）。
- `POST-005` `θ*` / `E*` 有限，无缺失、无 NaN；S03 点集与 `PRE-001` 网格一致。
- `POST-006` 采样种子与采样数记入 manifest（格式由 plan 定）。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 未达优化器收敛判据的点判 invalid（经 `INV-002` 接受者除外；
  `p=1` 始终适用严格收敛判据，不得以未收敛参数充数）。
- `INV-002` 棘轮接受门（仅 `p>1` 链）：精修跑满最大迭代仍未触发梯度判据时，
  若同时满足 (i) 末段能量停滞（后 200 步 `ΔE` 小于 plan 定阈值）与
  (ii) `E ≤ 同路上一层已收敛最优值 + 容限`（只许更好），则接受该点，
  旗子记 `stagnant`（与 `converged` 区分存档）。
- `INV-003` `E*` 不低于精确基态能量 `E0`（变分原理；数值容限由 plan 定）。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `POST-002`：`E* ≤ E_init` 硬断言。
- `VAL-002` → verifies `POST-003`：守恒量三项容限内。
- `VAL-003` → verifies `POST-004`：`δ=0` 参数计数 `= Lp/2`。
- `VAL-004` → verifies `INV-001`、`INV-002`：收敛旗逐路断言
  （`converged || stagnant`）；`stagnant` 仅出现在 `p>1`，
  且 `dE_tail` 与棘轮不等式由存档值重算锁定。
- `VAL-005` → verifies `POST-001`、`POST-005`、`INV-003`：
  `a*` 为三路最小能量对应路；S03 `594` 组形状与 `PRE-001` 网格一致
  且 `θ*` 与 S06 同点值相等；manifest 主根 / 采样数 / 阈值齐全；
  无缺失、无 NaN；每点经暴力本征值得精确 `E0` 交叉（`E* ≥ E0 − 容限`）。
- `VAL-006` → verifies `BND-003`：D06a–c 人工保真核对
  （轨道数 / 配对 / 子层顺序 / `p` 堆叠与 ansatz.md 一致，无虚构门）；
  S06 诊断图坐标系与数据一致（脚本自检断言）。
- `VAL-007`（诊断，只记录不设通过阈值）：`p` 单调性违反计数；
  `E*−E0` 精确 gap 分布；`a*` 分布；L-BFGS 迭代数分布；invalid 点清单。
  `p` 增大时 `E*` 是否单调不增只作诊断，不作硬断言；
  `δ` 大处的定性行为归论文解释。
- `VAL-008`（invalid-run）→ verifies `INV-001`、`POST-003`、`POST-005`：
  优化器未收敛（`p>1` 经棘轮门接受者除外）；对称性破缺
  （守恒量漂移超 plan 定阈值）；`θ*` / `E*` 缺失或非有限；
  S03 点集与 `PRE-001` 定义不符——出现任一情况，相关点（或整批）判 invalid，
  不得静默出图 / 入库。
