# Feature: exp04 模拟机 VQE

## 1. 目标

在态矢量模拟机上沿两条 `δ` 线做 VQE，产出 S06（`p=1,2,3` 拟设电路的曲线结果，
D08 模拟机图层底数）、S03（S06 的 `θ*` 视图，供 exp06 真机消费）与
D06a–c（三分相拟设结构示意图，纯示意）。
本 feature 只生产 D06a–c、S06、S03，不负责其他观测量与实验。

## 2. 边界

负责：

- S06：`δ=0` 与 `δ=0.85` 两条线上每点 `p=1,2,3` 的 VQE 结果曲线数据
  （每线 99 点，去边界；每点存 `θ*`、`E*` 及 `S(π)` 与 string，见 §3）。
- S03：全网格最优参数（`2×99×3=594` 组 `θ*`，供 exp06 消费）。
- D06a–c：三分相拟设结构示意图（trivial / topo / AFM，每相初态 + 所需拟设电路；
  纯示意，无数据依赖；须如实反映 `doc/theory/ansatz.md`
  的轨道分组、奇偶子层与 `p` 层堆叠，不虚构门类型与连接）。

不负责：

- S01 / S02 基态与 D01–D05（shared-01、exp01、exp02，保持开放引用，不消费、
  不复算；三路取最小策略不引用 D01 相区）。
- 能隙标度（exp03）、真机优质比特与 S04（exp05）、真机测量与 D08（exp06）。

依赖：

- 无外部数据依赖（自含；模型见 `doc/theory/H.md`，拟设见
  `doc/theory/ansatz.md`，初态见 `doc/theory/psi0.md`，代价策略见
  `doc/theory/cost_fun.md`）。三路取最小不引用 D01 相区，故无对 exp01 的
  读依赖。

## 3. 实验 / 计算定义

- 系统 / 模型：SSH XXZ 链，OBC，`L=8`（拟设中 `L=8`，见 `doc/theory/ansatz.md`），
  哈密顿量 `H(s,δ)` 定义见 `doc/theory/H.md`。
- 拟设：orbit 拟设，定义见 `doc/theory/ansatz.md`（轨道分组、每轨道
  `(θ,φ)`、`δ=0` 时 `θ=φ` 参数减半、子层顺序与初态配对、
  `U^{(l)}=U^{(l)}_S U^{(l)}_F`，`p=1,2,3`，参数量 `Nθ=Lp`（`δ≠0`）或
  `Lp/2`（`δ=0`））。
- 初态：三参考态见 `doc/theory/psi0.md`（平庸奇键单态 / 拓扑 bulk+首尾单态 /
  AFM GHZ），均为 `P=−2` 扇区；每点三初态各做一路优化，取综合最小
  （见 `doc/theory/cost_fun.md`：`C*(s*,δ*) = min_a min_θ C_a(θ)`，
  每路内可用多种子 restart，同样取最小）。
- 代价函数：`E(θ) = ⟨ψ(θ)|H(s,δ)|ψ(θ)⟩`（态矢量精确期望，无采样噪声、
  无硬件噪声；噪声模型归 exp06，不属本实验）。
- 两线：`δ=0` 与 `δ=0.85`（D08 四面板的两线，见 `paper-outline.md` D08）；
  `s` 网格每线 99 点、去边界，`s ∈ [0,1]`、`s=i/100`（与 S01 同约定，已确认）。
- 每点输出量：三路各自的 `θ*_a`、`E*_a` 取最小者为 `θ*`、`E*`（须同时存档
  获胜初态标签 `a*`），外加该最优态上的 `S(π)` 与 string 期望。
- 求解策略：`p=1` 时全局随机采样 + 局域 L-BFGS 精修；`p>1` 时同路链式
  warm start（`a` 路 `p=2` 初值取同路 `p=1` 最优参数，`p=3` 取同路 `p=2`
  最优参数）后再做局域 L-BFGS 精修至收敛，新增层参数初始化与采样数/收敛阈值
  由 plan 定；全局采样集须含零向量（恒等层对应初态本身，保证
  `E* ≤ E(θ_init)` 构造性成立）。
  种子与采样必须记录（宪法 IV）；未收敛点判 invalid（见 §5）。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- S06：每 `(δ,s,p)` 点的三路最优（`θ*_a`、`E*_a`，`a` 取遍三初态）取最小者
  `θ*`、`E*` + 获胜初态标签 `a*` + 该态 `S(π)`、string 期望；
  每点附参数元数据 `(δ,s,p,L)`。
- S03：全网格 `594` 组 `(δ,s,p,θ*,a*)`（须含 exp06 可复现所需的
  初态/拟设标识）。
- D06a–c：三分相拟设结构示意图（版式由实现层安排）。
- 具体落盘格式与存储路径由 plan 确定；须保证可按 `(δ,s,p)` 检索，
  exp06 可按点取用 S03。

## 5. 验证

- 正确性条件：每点 `E* ≤ E(θ_init)`（VQE 不劣于初态）；终态守恒量
  （`Z_tot`、`∏X`、`R`）与初态一致（拟设保对称，见 `doc/theory/ansatz.md`）；
  `δ=0` 时参数满足 `θ=φ` 约束；无缺失、无 NaN。
- 收敛 / 稳定性要求：优化器收敛判据与最大迭代由 plan 定（Q4 定选型）；
  未达判据的点判 invalid，不得以未收敛参数充数；但 `p>1` 链式精修适用
  棘轮接受门（2026-10-04 确认）：跑满最大迭代仍未触发梯度判据时，
  若同时满足 (i) 末段能量停滞（后 200 步 `ΔE` 小于 plan 定阈值）与
  (ii) `E ≤ 同路上一层已收敛最优值 + 容限`（只许更好），则接受该点，
  旗子记 `stagnant`（与 `converged` 区分存档）；`p=1` 不适用此门，
  始终严格收敛判据。
- 参考解 / benchmark：`p` 增大时 `E*` 是否单调不增只作诊断记录，
  不作硬断言（`p+1` 层能否精确还原 `p` 层取决于拟设参数化是否存在恒等层，
  本 spec 不预设；具体由 plan 定）；`δ` 大处的定性行为归论文解释。
- invalid run 判据：优化器未收敛（`p>1` 链被棘轮门接受者除外，旗 `stagnant`）；
  对称性破缺（守恒量漂移超 plan 定阈值）；
  `θ*`/`E*` 缺失或非有限；S03 点集与 Q3 定义不符——出现任一情况
  相关点（或整批）判 invalid，不得静默出图/入库。
