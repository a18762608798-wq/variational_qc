# Feature: exp05 真机优质比特

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

在真机超导芯片上实测筛选优质物理比特，为真机 VQE（exp06）确定目标比特。
产出 D07a（`8` 链评分排名前十）、D07b（`10` 环评分排名前十）、
D07c（冠军环内十条 `8`-子链评分排名）与 S04（真机目标比特，供 exp06 消费）。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 候选：芯片耦合拓扑上的连续 `8` 比特链（开边界）与 `10` 比特环（闭合）。
  目标芯片为 Baihua 与 Shenglian 两台，链 / 环候选跨芯片枚举、
  各自内部排序（链与环之间不混排比较，`POST-003`）。
  逻辑比特 `0..n-1` 按候选顺序映射到物理比特，电路拓扑即候选子图本身
  （`INV-001`）。
- 基准电路：每候选 `4` 个——`stab_g0` / `stab_g1`（cluster 态制备 +
  奇偶分组单比特转基矢测量，得各 `⟨S_i⟩`）与 `allzero` / `allone`
  （裸测量 / 全 `X` 后测量，得读出保真度）。定义见
  `doc/theory/premium_qubits.md`。每电路 shots 数 `2048`（`PRE-002`）。
- 稳定子均值 `S̄ = (1/n)Σ_i⟨S_i⟩`（`n=8` 链含端点二体项，`n=10` 环全三体、
  指标模 `10`）；读出保真度 `F_ro = [P(全0) + P(全1)] / 2`
  （`allzero` / `allone` 电路不含 `CZ`，`POST-002`）。
- 打分 `score = 0.8·S̄ + 0.2·F_ro`（双比特门优先，读出只占辅助位；
  见 `doc/paper-outline.md` 与 `doc/theory/premium_qubits.md`）。
  环分系统性低于链分，只各自内部排序，不混排比较（`POST-003`）。
- 枚举范围（`PRE-001`）：`8` 链按静态边保真度排序采样截断、每芯片至多
  `3000` 条（去重后计数；采样排序与卫生过滤细则由 plan 定）；
  `10` 环全枚举全测。
- 两步闸门：离线预览（拓扑拉取命中缓存、零机时，打印任务账单）→
  人工确认账单后才真机提交（`INV-003`，`PRE-003`）。
- D07c：冠军环内 `10` 条连续 `8`-子链的评分排名；子链评分优先引用链任务
  已实测 evidence（零机时 join），引用须可追溯到链任务候选记录；
  未被链任务覆盖的子链由本任务补测（同基准电路与 shots，`POST-004`）。
- S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表 + 拓扑快照标识）；
  若首名分差 `< 0.02` 则判并列，并列者全部记入 S04（`POST-005`）。

### 3. Outputs

- D07a：`8` 链全候选 evidence（每候选：芯片、物理比特表、`S̄`、`F_ro`、
  `score`、拓扑快照引用）+ 评分前十排名。
- D07b：`10` 环全候选 evidence（字段同上）+ 评分前十排名。
- D07c：冠军环内十条连续 `8`-子链评分排名（字段同上，另注每条子链评分
  来源：引用链任务实测 / 本任务补测）。
- S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表 + 拓扑快照标识），
  exp06 可直接取用。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II
（`POST-001`、`POST-004`、`POST-005`、`POST-007`）。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D07a：`8` 比特链全候选实测 evidence + 评分前十排名。
- `BND-002` D07b：`10` 比特环全候选实测 evidence + 评分前十排名。
- `BND-003` D07c：冠军环内 `10` 条连续 `8`-子链的评分排名。
- `BND-004` S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表，
  供 exp06 开 / 周期边界两用）。

#### Out of Scope

- `BND-005` S01 / S02 基态与 D01–D05（shared-01、exp01、exp02）、
  能隙标度（exp03）、模拟机 VQE 与 S03（exp04）。
- `BND-006` 真机测量与 D08（exp06，含读出分配矩阵 S05 与读出误差缓解；
  本实验只测裸 `F_ro`）。

#### Dependencies

- `DEP-001` 无外部数据依赖（自含；筛选方法见
  `doc/theory/premium_qubits.md`）。真机提交经现有真机工具链
  （拓扑拉取 / 转译 pin / 任务轮询），所用栈名与版本须记入 manifest
  （plan 落实记录方式）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `S̄`：稳定子均值，`(1/n)Σ_i⟨S_i⟩`（`n=8` 链含端点二体项，
  `n=10` 环全三体、指标模 `10`）。
- `F_ro`：读出保真度，`[P(全0) + P(全1)] / 2`。
- `score = 0.8·S̄ + 0.2·F_ro`：候选打分。
- `tid`：真机提交任务标识（提交 / 收回对账单位）。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 候选枚举集：`8` 链按静态边保真度排序采样截断、每芯片至多
  `3000` 条（去重后计数；不足则有多少测多少，不凑数）；
  `10` 环全枚举全测。链候选无向去重（链与其反转视为同一候选）；
  环候选旋转 / 翻转等价视为同一候选。
- `PRE-002` 基准电路：每候选 `4` 个（`stab_g0` / `stab_g1` / `allzero` /
  `allone`），每电路 shots 数 `2048`。
- `PRE-003` 离线预览账单须经人工确认；未确认前不得进入真机提交。
- `PRE-004` 拓扑快照须含 `calibration_time`。

### D. Postconditions

定义一次成功计算完成后必须成立的条件（除注明外，均按候选计）。

- `POST-001` 每候选 `4` 电路结果齐全；`S̄ ∈ [-1, 1]`，`F_ro ∈ [0, 1]`；
  无缺失、无 NaN。
- `POST-002` 转译门：转译后 `CZ` 数 == 候选边数（链 `7` / 环 `10`）
  且作用比特集 ⊆ 候选；`allzero` / `allone` 依定义不含 `CZ`。
- `POST-003` 打分 `score = 0.8·S̄ + 0.2·F_ro`；链 / 环各自内部排序，
  不混排比较。
- `POST-004` D07c：冠军环内 `10` 条连续 `8`-子链评分排名；每条子链评分来源
  可追溯（引用链任务候选记录 / 本任务补测任务 `tid`）；未被链任务覆盖的
  子链由本任务补测（同 `PRE-002` 电路与 shots，同样提交 / 对账 / 落盘）。
- `POST-005` S04：冠军链与冠军环各自的芯片 + 物理比特表 + 拓扑快照标识；
  首名分差 `< 0.02` 时并列者全部记入（链 / 环各自判定）；
  S04 比特表与快照拓扑相容（候选边确为可用边）。
- `POST-006` 提交 / 收回对账：提交任务数与收回结果数一致
  （`tid` 清单 == 收回成功集 + 明确标记集）；中断续跑只补缺失候选
  （有 `tid` 只轮询不重提，已收回永不重提）。
- `POST-007` 逐候选增量落盘；产品层写
  `exp05_{D07a,D07b,D07c,S04}.npz` + `exp05_manifest.json`
  （schema `exp05/v1`，含芯片 / 快照标识 / `rng_seed` / 过滤阈值 / shots /
  工具栈名与版本 / 解释器路径）；须保证可按候选检索，exp06 可按需取用 S04。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 转译不得引入候选子图之外的纠缠门：逻辑比特按候选顺序映射，
  `coupling_map` 即候选边集，测的就是该候选本身。
- `INV-002` 卫生过滤：静态边保真度 `< 0.9` 的边所在候选剔除
  （阈值与剔除数记入 prescreen 清单 + manifest；过滤后不足 `3000`
  即有多少测多少，不降阈凑数）。
- `INV-003` 未经人工确认的账单不得提交（两步闸门；经明确提前授权并留记录者，
  视为已确认——用户 2026-10-04 授权“校准稳定即自动测量”，记录见账单
  `confirmed_by`）。
- `INV-004` Failed 任务须重跑收回或明确标记，不得静默丢弃。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `POST-001`：每候选 `4` 电路齐全，无缺失 / NaN；
  `S̄ ∈ [-1,1]`，`F_ro ∈ [0,1]`。
- `VAL-002` → verifies `POST-002`、`INV-001`：转译后 `CZ` 数与比特集留存可查。
- `VAL-003` → verifies `POST-006`、`INV-004`：`tid` 清单 == 收回成功集 +
  明确标记集，无静默丢弃；checkpoints 与 npz evidence 逐候选一致
  （`score_chain` 复算比对）。
- `VAL-004` → verifies `POST-004`：D07c 每条子链来源可追溯
  （引用链候选 id / 补测任务 `tid`）。
- `VAL-005` → verifies `POST-003`、`POST-005`：链 / 环排名复算；
  并列判定复算（阈值 `0.02`）；S04 比特表与快照拓扑相容。
- `VAL-006` → verifies `PRE-004`、`POST-007`：拓扑快照含 `calibration_time`；
  manifest 必填字段齐全。
- `VAL-007`（诊断，只记录不作硬门）：实测 `S̄` 应显著偏离理想值 `1.0`
  且按候选质量单调退化（硬件真实执行的签名；若 `CZ` 未真实执行
  `S̄` 应 `≈ 1.0`）；冠军 `S̄ > 0.95` 标记可疑；退化单调性；
  稳定子–读出相关系数。异常阈值由 plan 定。
- `VAL-008`（invalid-run）→ verifies `POST-001`、`INV-001`、`PRE-004`、
  `POST-004`：任一电路结果缺失；转译引入候选子图之外的纠缠门；
  拓扑快照缺 `calibration_time`；D07c 子链评分无可追溯来源——出现任一情况
  相关候选（或整批）判 invalid，不得静默排名 / 入库。
