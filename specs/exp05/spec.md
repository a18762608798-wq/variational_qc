# Feature: exp05 真机优质比特

## 1. 目标

在真机超导芯片上实测筛选优质物理比特，为真机 VQE（exp06）确定目标比特。
产出 D07a（`8` 链评分排名前十）、D07b（`10` 环评分排名前十）、D07c（冠军环内
十条 `8`-子链评分排名）与 S04（真机目标比特，供 exp06 消费）。
本 feature 只生产 D07a、D07b、D07c、S04，不负责其他观测量与实验。

## 2. 边界

负责：

- D07a：`8` 比特链全候选实测 evidence + 评分前十排名。
- D07b：`10` 比特环全候选实测 evidence + 评分前十排名。
- D07c：冠军环内 `10` 条连续 `8`-子链的评分排名。
- S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表，供 exp06
  开/周期边界两用）。

不负责：

- S01 / S02 基态与 D01–D05（shared-01、exp01、exp02）、能隙标度（exp03）、
  模拟机 VQE 与 S03（exp04）。
- 真机测量与 D08（exp06，含读出分配矩阵 S05 与读出误差缓解）。

依赖：

- 无外部数据依赖（自含；筛选方法见 `doc/theory/premium_qubits.md`）。
  真机提交经现有真机工具链（拓扑拉取 / 转译 pin / 任务轮询），
  所用栈名与版本须记入 manifest（plan 落实记录方式）。

## 3. 实验 / 计算定义

- 候选：芯片耦合拓扑上的连续 `8` 比特链（开边界）与 `10` 比特环（闭合）。
  目标芯片为 Baihua 与 Shenglian 两台，链 / 环候选跨芯片枚举、
  各自内部排序（链与环之间不混排比较，见下）。
  逻辑比特 `0..n-1` 按候选顺序映射到物理比特，电路拓扑即候选子图本身，
  转译不得绕路改道（测的就是该候选本身，不得引入候选子图之外的纠缠门）。
- 基准电路：每候选 `4` 个——`stab_g0` / `stab_g1`（cluster 态制备 +
  奇偶分组单比特转基矢测量，得各 `⟨S_i⟩`）与 `allzero` / `allone`
  （裸测量 / 全 `X` 后测量，得读出保真度）。定义见
  `doc/theory/premium_qubits.md`。
- 稳定子均值 `S̄ = (1/n)Σ_i⟨S_i⟩`（`n=8` 链含端点二体项，`n=10` 环全三体、
  指标模 `10`）；读出保真度 `F_ro = [P(全0) + P(全1)] / 2`
 （`allzero` / `allone` 电路不含 `CZ`）。
- 打分 `score = 0.8·S̄ + 0.2·F_ro`（双比特门优先，读出只占辅助位；
  见 `doc/paper-outline.md` 与 `doc/theory/premium_qubits.md`）。
  环分系统性低于链分，只各自内部排序，不混排比较。
- 去重：链候选无向去重（链与其反转视为同一候选）；
  环候选旋转 / 翻转等价视为同一候选。
- 枚举范围：`8` 链按静态边保真度排序采样截断、每芯片至多 `3000` 条
  （去重后计数；采样排序与卫生过滤细则由 plan 定）；
  `10` 环全枚举全测。每电路 shots 数 `2048`；未定事项（Q4–Q6）
  落定之前不得提交机时。
- 两步闸门：离线预览（拓扑拉取命中缓存、零机时，打印任务账单）→
  人工确认账单后才真机提交。
- 拓扑快照须记录 `calibration_time`；逐候选增量落盘，中断续跑只补缺失
  （宪法 IV）；提交与收回逐任务对账（见 §5）。
- D07c：冠军环内 `10` 条连续 `8`-子链的评分排名；子链评分优先引用链任务
  已实测 evidence（零机时 join），引用须可追溯到链任务候选记录；
  未被链任务覆盖的子链由本任务补测（同 §3 基准电路与 shots）。
- S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表 + 拓扑快照标识）；
  若首名分差 `< 0.02` 则判并列，并列者全部记入 S04，由 exp06 / 论文解释选用。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- D07a：`8` 链全候选 evidence（每候选：芯片、物理比特表、`S̄`、`F_ro`、
  `score`、拓扑快照引用）+ 评分前十排名。
- D07b：`10` 环全候选 evidence（字段同上）+ 评分前十排名。
- D07c：冠军环内十条连续 `8`-子链评分排名（字段同上，另注每条子链评分
  来源：引用链任务实测 / 本任务补测，见 Q4）。
- S04：真机目标比特（冠军链与冠军环的芯片 + 物理比特表 + 拓扑快照标识），
  exp06 可直接取用。
- 具体落盘格式与存储路径由 plan 确定；须保证可按候选检索，
  exp06 可按需取用 S04。

## 5. 验证

- 正确性条件：每候选 `4` 电路结果齐全；`S̄ ∈ [-1, 1]`，
  `F_ro ∈ [0, 1]`；无缺失、无 NaN；拓扑快照含 `calibration_time`。
- 提交 / 收回对账：提交任务数与收回结果数一致；Failed 任务须重跑收回
  或明确标记，不得静默丢弃；中断续跑只补缺失候选，不得重提已收回任务。
- 可信度诊断（只记录，不作硬门）：实测 `S̄` 应显著偏离理想值 `1.0`
  且按候选质量单调退化（硬件真实执行的签名；若 `CZ` 未真实执行
  `S̄` 应 `≈ 1.0`）；异常由 plan 定阈值标记可疑。
- invalid run 判据：任一电路结果缺失；转译引入候选子图之外的纠缠门；
  拓扑快照缺 `calibration_time`；D07c 子链评分无可追溯来源——出现任一情况
  相关候选（或整批）判 invalid，不得静默排名 / 入库。
