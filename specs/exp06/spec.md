# Feature: exp06 真机测量与比较

## 1. 目标

在真机目标比特（S04）上执行 VQE 最优电路的观测量测量，产出 D08
真机图层（`p=1,2,3` 全量测量，`p*` 最优层进图 + 误差棒；与 S06 模拟机图层
叠放并各自归一化比趋势），自含 S05（读出分配矩阵）。
本 feature 只生产 D08（真机侧）、S05，不负责其他观测量与实验。

## 2. 边界

负责：

- D08 真机图层：两线上稀疏点每点 `p=1,2,3` 的真机 `S(π)` 与 string 全量测量
  （读出缓解后）；出图时每 `(δ,观测量)` 面板只放 `p*` 最优层散点及估计标准差
  误差棒（`p*` 选取规则见 §4）。
- D08 叠放比较：真机 `p*` 散点与 S06 模拟机 `p=1,2,3` 曲线同图，真机与模拟机
  各自内部 `0–1` 归一化后比趋势（模拟机侧引用 exp04 S06，不复算）。
- S05：逐需读出比特的 `2×2` 读出分配矩阵（自含，每批 fresh，见 §3）。

不负责：

- S01 / S02 基态与 D01–D05（shared-01、exp01、exp02）、能隙标度（exp03）。
- 模拟机 VQE（exp04，S06/S03 只消费不复算）、优质比特筛选（exp05，
  D07a–c/S04 只消费不复算）。

依赖：

- S03（exp04 最优参数 `θ*` + 初态/拟设标识，供每点电路参数）。
- S04（exp05 真机目标比特：冠军 `8` 链与冠军环 + 快照标识）。
- S06（exp04，D08 模拟机图层底数）。

## 3. 实验 / 计算定义

- 测点：`δ=0` 与 `δ=0.85` 两线，每线 `33` 点（`s=i/100`，
  `i=1,4,7,…,97`，即 S01 网格每 `3` 点取 `1`）；每点 `p=1,2,3`
 （见 `doc/paper-outline.md` D08）。
- 电路参数：每 `(δ,s,p)` 取 S03 同点最优 `(θ*,a*)`（三路取最小的获胜路；
  S03 无此点则该点判 invalid，不另做优化）。
- 目标比特（只用 top1，并列者不用；用户 2026-10-04 确认）：
  - 平庸 / AFM 初态：S04 冠军 `8` 链（Baihua `[77,…,70]`），开链
    `coupling_map`。
  - 拓扑初态：冠军环内最优 `8`-子链（D07c Rank1，取值以新 S04 为准，
    当前值为 run1 快照，exp05 重跑后刷新）为 `8` 计算比特；
    首尾单态（`0–7` 对）在逻辑 `0–7` 上正常摆，`coupling_map` 取环状
    （子链 `7` 边 + `0–7` 闭合边），经由环剩余 `2` 比特的绕行由转译器
    完成——该绕行是本实验定义的 link 语义，不判转译 invalid。
- 转译：`qiskit`，`optimization_level=3`，`coupling_map` 显式传入
  （上条），`basis_gates` 由 plan 定并记入 manifest。
- 观测量：`S(π)` 与 string 经 estimator 测（qubitwise 对易分组，
  定义见 `doc/theory/topological_op.md`）；每 estimator 电路
  shots `2048`、独立重复 `5` 次，重复间标准差为 D08 真机散点误差棒。
- 读出缓解（S05）：逐需读出比特（`8` 计算比特）各标定 `2×2` 分配矩阵
  （制备 `|0⟩` / `|1⟩` 各一电路，定义见
  `doc/theory/readout_mitigation.md`）；  `8` 比特可同时测量，
  故每批只需 `2` 个标定电路（全 `0` 制备 + 全 `X` 制备，一次给出
  `8` 比特各自的两列），与正式电路同 shots；批量度为每 `3` 个
  `(δ,s,p)` 组一切批（该批内该 `3` 组的全部 estimator 电路及 `5` 次重复
  + 紧跟 `2` 个标定电路，该批数据只用该批矩阵矫正，不跨批复用）；quark 平台自带读出矫正必须关闭
  （`correct=False`，平台侧键名；防双重矫正干扰；缓解后加非负约束再算观测量）。
- 两步闸门与落盘沿用 exp05 模式：离线预览打印账单 → 人工确认后提交；
  拓扑快照记 `calibration_time`；逐点增量落盘，中断续跑只补缺失；
  提交/收回逐任务对账。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- D08 真机图层：每 `(δ,s,p)` 的真机 `S(π)`、string 缓解后均值 + `5` 次重复标准差
  （误差棒）；每重复独立存档：原始 counts（稀疏，只存非零 bin）、
  缓解前观测量、缓解后观测量（三者缺一不可，缓解前数据不得丢弃）；
  每点附 `(δ,s,p,L=8)`、所用 S03 记录引用、S05 批次引用。
- `p*` 选取（出图用，全量数据照常存档）：每 `(δ,观测量)` 面板取
  `p* = argmin_p mean_s |hw_p(s) − sim_p(s)|`（33 点平均，真机缓解后均值
  vs S06 同层同点值；并列取小 `p`）；所选 `p*` 与 33 点偏差均值记入 manifest。
- D08 叠放归一化：真机 `p*` 散点与 S06 同面板模拟机 `p=1,2,3` 曲线各自内部
  `0–1` 归一化后同图比趋势（归一化只比趋势不比绝对值，见 paper-outline；
  归一化区间记入 manifest，可复算）。
- S05：每批次 `2` 个标定电路给出的每比特 `2×2` 分配矩阵 + 批次引用
  （exp06 内自产自用，不出独立产品文件，随 D08 存档）。
- 具体落盘格式与存储路径由 plan 确定；须保证可按 `(δ,s,p)` 检索，
  D08 叠放可引用 S06 对应点。

## 5. 验证

- 正确性条件：每点 `5` 次重复齐全；`S(π)`、string 缓解前后值皆存档；
  所用 `θ*` 与 S03 同点记录一致（逐点比对）；S05 与 VQE 同批
  （每 `3` 点一批，批次 id 一致）；  平台矫正关闭可查（提交参数 `correct=False` 留存）。
- 提交 / 收回对账：任务数与收回数一致；Failed 重跑或明确标记，
  不得静默丢弃；中断续跑只补缺失，不得重提已收回。
- 诊断（只记录）：缓解前后差值分布；`5` 次重复离散度异常标记
  （阈值 plan 定）；真机–模拟机单调趋势一致性（D08 目检，不设硬门）。
- invalid run 判据：S03 缺对应点；重复次数不足 `5`；S05 非同批；
  平台矫正未关闭（`correct` 非 `False`）；观测量非有限；转译路径违规（转译后电路的 `CZ` 边集
  未落入允许集内，允许集 = 子链相邻边 + topo `0–7` 绕行 `0-10-9-7`；
  采用验路断言方案，不采用"候选外一律 invalid"；若实测未走 `10-9`，
  另议换最优 `8` 链）——出现任一情况相关点判 invalid，
  不得出图/入库。
