# Feature: exp06 真机测量与比较

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

在真机目标比特（S04）上执行 VQE 最优电路的观测量测量，产出 D08
真机图层（`p=1,2,3` 全量测量，`p*` 最优层进图 + 误差棒；与 S06 模拟机图层
叠放并各自归一化比趋势），自含 S05（读出分配矩阵）。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 测点（`PRE-001`）：`δ=0` 与 `δ=0.85` 两线，每线 `33` 点
  （S01 网格每 `3` 点取 `1`）；每点 `p=1,2,3`
  （见 `doc/paper-outline.md` D08）。
- 电路参数：每 `(δ,s,p)` 取 S03 同点最优 `(θ*,a*)`（三路取最小的获胜路；
  S03 无此点则该点判 invalid，不另做优化，`PRE-002`）。
- 目标比特（只用 top1，并列者不用；用户 2026-10-04 确认，`PRE-003`）：
  - 平庸 / AFM 初态：S04 冠军 `8` 链，开链 `coupling_map`。
  - 拓扑初态：冠军环内最优 `8`-子链（D07c Rank1，取值以新 S04 为准）
    为 `8` 计算比特；首尾单态（`0–7` 对）在逻辑 `0–7` 上正常摆，
    `coupling_map` 取环状（子链 `7` 边 + `0–7` 闭合边），
    经由环剩余 `2` 比特的绕行由转译器完成——该绕行是本实验定义的
    link 语义，不判转译 invalid（`INV-003`）。
  - 注：run1 快照的具体比特表（冠军链 `[77,…,70]`、D07c Rank1 子链）仅为
    当时取值，不属合同；exp05 重跑落盘新 S04 后以新值为准（见 T008）。
- 转译：`qiskit`，`optimization_level=3`，`coupling_map` 显式传入
  （上条），`basis_gates` 由 plan 定并记入 manifest（`PRE-004`）。
- 观测量：`S(π)` 与 string 经 estimator 测（qubitwise 对易分组，
  定义见 `doc/theory/topological_op.md`）；每 estimator 电路
  shots `2048`、独立重复 `5` 次（5 片分批，各带当批 S05 矩阵，防漂移，
  `PRE-005`）；误差棒为全并 multinomial 解析标准误（5 批缓解后分布平均，
  `N=5×2048`，`POST-001`）。
- 读出缓解（S05，`PRE-006` / `POST-004`）：逐需读出比特（`8` 计算比特）
  各标定 `2×2` 分配矩阵（制备 `|0⟩` / `|1⟩` 各一电路，定义见
  `doc/theory/readout_mitigation.md`）；`8` 比特可同时测量，
  故每批只需 `2` 个标定电路（全 `0` 制备 + 全 `X` 制备，一次给出
  `8` 比特各自的两列），与正式电路同 shots；批量度为每 `3` 个
  `(δ,s,p)` 组一切批；quark 平台自带读出矫正必须关闭
  （`correct=False`，平台侧键名；防双重矫正干扰；缓解后加非负约束
  再算观测量，`INV-001`）。
- 两步闸门与落盘沿用 exp05 模式（`INV-004`）：离线预览打印账单 →
  人工确认后提交；拓扑快照记 `calibration_time`；逐点增量落盘，
  中断续跑只补缺失；提交 / 收回逐任务对账（`POST-006`）。

### 3. Outputs

- D08 真机图层：每 `(δ,s,p)` 的真机 `S(π)`、string 缓解后均值 + 全并解析
  标准误（误差棒）；每重复独立存档原始 counts、缓解前观测量、
  缓解后观测量（三者缺一不可）。
- `p*` 选取（出图用，全量数据照常存档）：面板各自归一化后同层对标，
  `p* = argmin_p mean_s |A_p(s) − B_p(s)|`（`POST-002`）。
- D08 叠放：真机 `p*` 散点与 S06 同面板模拟机 `p=1,2,3` 曲线各自内部
  `0–1` 归一化后同图比趋势（`POST-003`）。
- S05：每批次标定矩阵 + 批次引用，随 D08 存档（`POST-004`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` D08 真机图层：两线上稀疏点每点 `p=1,2,3` 的真机 `S(π)` 与
  string 全量测量（读出缓解后）；出图时每 `(δ,观测量)` 面板只放 `p*`
  最优层散点及估计标准差误差棒。
- `BND-002` D08 叠放比较：真机 `p*` 散点与 S06 模拟机 `p=1,2,3` 曲线同图，
  真机与模拟机各自内部 `0–1` 归一化后比趋势（模拟机侧引用 exp04 S06，
  不复算）。
- `BND-003` S05：逐需读出比特的 `2×2` 读出分配矩阵（自含，每批 fresh）。

#### Out of Scope

- `BND-004` S01 / S02 基态与 D01–D05（shared-01、exp01、exp02）、
  能隙标度（exp03）。
- `BND-005` 模拟机 VQE（exp04，S06 / S03 只消费不复算）、优质比特筛选
  （exp05，D07a–c / S04 只消费不复算）。

#### Dependencies

- `DEP-001` S03（exp04 最优参数 `θ*` + 初态 / 拟设标识，供每点电路参数）。
- `DEP-002` S04（exp05 真机目标比特：冠军 `8` 链与冠军环 + 快照标识）。
- `DEP-003` S06（exp04，D08 模拟机图层底数）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- `A_p`：归一化后真机 `p` 层 33 点（某 `(δ,观测量)` 面板）。
- `B_p`：归一化后模拟机同层 `p` 曲线（同面板 33 点）。
- `p* = argmin_p mean_s |A_p(s) − B_p(s)|`：同层对标最优层
  （并列取小 `p`）。
- S05：每比特 `2×2` 读出分配矩阵；全并解析标准误按 `N=5×2048`
  multinomial 闭式。
- link 语义：topo `0–7` 绕行是本实验定义的转译行为（`INV-003`）。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 测点网格：`δ ∈ {0, 0.85}`，每线 `33` 点（`s=i/100`，
  `i=1,4,7,…,97`，即 S01 网格每 `3` 点取 `1`）；每点 `p=1,2,3`。
- `PRE-002` 电路参数：每 `(δ,s,p)` 取 S03 同点最优 `(θ*,a*)`；
  S03 无此点则该点判 invalid，不另做优化。
- `PRE-003` 目标比特（只用 top1，并列者不用）：平庸 / AFM 初态用 S04
  冠军 `8` 链（开链 `coupling_map`）；拓扑初态用冠军环内最优 `8`-子链
  为 `8` 计算比特，首尾单态（`0–7` 对）在逻辑 `0–7` 上正常摆，
  `coupling_map` 取环状（子链 `7` 边 + `0–7` 闭合边），经由环剩余
  `2` 比特的绕行由转译器完成。
- `PRE-004` 转译：`qiskit`，`optimization_level=3`，`coupling_map`
  显式传入（`PRE-003`），`basis_gates` 由 plan 定并记入 manifest。
- `PRE-005` 观测量协议：`S(π)` 与 string 经 estimator 测
  （qubitwise 对易分组）；每 estimator 电路 shots `2048`、独立重复
  `5` 次（5 片分批，各带当批 S05 矩阵，防漂移）。
- `PRE-006` S05 标定：逐需读出比特（`8` 计算比特）各标定 `2×2` 分配矩阵
  （制备 `|0⟩` / `|1⟩` 各一电路）；`8` 比特可同时测量，故每批只需
  `2` 个标定电路（全 `0` 制备 + 全 `X` 制备），与正式电路同 shots；
  批量度为每 `3` 个 `(δ,s,p)` 组一切批（该批内该 `3` 组的全部 estimator
  电路及 `5` 次重复 + 紧跟 `2` 个标定电路）；quark 平台自带读出矫正
  必须关闭（`correct=False`，平台侧键名，防双重矫正干扰）。

### D. Postconditions

定义一次成功计算完成后必须成立的条件（除注明外，均按 `(δ,s,p)` 点计）。

- `POST-001` D08 真机图层：真机 `S(π)`、string 缓解后均值 + 全并解析
  标准误（5 批缓解后分布平均，`N=5×2048` multinomial 闭式）；
  每重复独立存档：原始 counts（稀疏，只存非零 bin）、缓解前观测量、
  缓解后观测量（三者缺一不可，缓解前数据不得丢弃）；
  每点附 `(δ,s,p,L=8)`、所用 S03 记录引用、S05 批次引用。
- `POST-002` `p*` 选取（出图用，全量数据照常存档）：先按面板各自归一化
  （与 D08 归一化同区间）；每 `(δ,观测量)` 面板取
  `p* = argmin_p mean_s |A_p(s) − B_p(s)|`（并列取小 `p`）；所选 `p*`
  与 33 点偏差均值记入 manifest。
- `POST-003` D08 叠放归一化：真机 `p*` 散点与 S06 同面板模拟机 `p=1,2,3`
  曲线各自内部 `0–1` 归一化后同图比趋势（归一化只比趋势不比绝对值；
  归一化区间记入 manifest，可复算）。
- `POST-004` S05：每批次 `2` 个标定电路给出的每比特 `2×2` 分配矩阵 +
  批次引用（exp06 内自产自用，不出独立产品文件，随 D08 存档）。
- `POST-005` 每点 `5` 次重复齐全；所用 `θ*` 与 S03 同点记录一致
  （逐点比对）；S05 与 VQE 同批（每 `3` 点一批，批次 id 一致）；
  平台矫正关闭可查（提交参数 `correct=False` 留存）。
- `POST-006` 提交 / 收回对账：任务数与收回数一致；Failed 重跑或明确标记，
  不得静默丢弃；中断续跑只补缺失，不得重提已收回。
- `POST-007` 具体落盘格式与存储路径由 plan 确定；须保证可按 `(δ,s,p)`
  检索，D08 叠放可引用 S06 对应点。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` 缓解后加非负约束再算观测量。
- `INV-002` 该批数据只用该批矩阵矫正，不跨批复用。
- `INV-003` topo `0–7` 绕行是本实验定义的 link 语义，不判转译 invalid
  （转译路径以验路断言方案执行，不采用“候选外一律 invalid”）。
- `INV-004` 两步闸门与落盘：离线预览打印账单 → 人工确认后提交；
  拓扑快照记 `calibration_time`；逐点增量落盘。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `POST-005`：每组 5 重复齐全；`θ` 与 S03 逐元一致
  （`NaN`-pad 区除外）；S05 批次 id 同批；`correct=False` 留存可查。
- `VAL-002` → verifies `POST-001`：三件套存档完整性（逐组查 counts +
  缓解前 + 缓解后三样落盘，缺一报错）；全并解析标准误重算一致；
  观测量有限。
- `VAL-003` → verifies `POST-006`：任务数 == 收回数 + 明确标记；
  无静默丢弃；无已收回重提。
- `VAL-004` → verifies `POST-002`、`POST-003`：`p*` 复算；
  归一化区间与 manifest 一致，可复算。
- `VAL-005` → verifies `INV-003`：转译验路断言（边集落入允许集，
  由 checkpoints 留存的转译摘要重算比对）。
- `VAL-006` → verifies `POST-004`、`POST-007`：manifest 必填字段
  （`p*`、归一化区间、S03 引用、栈版本、转译参数）。
- `VAL-007`（诊断，只记录）：缓解前后差值分布；`5` 次重复离散度异常标记
  （漂移哨兵，阈值 plan 定）；真机–模拟机单调趋势一致性
  （D08 目检，不设硬门）。
- `VAL-008`（invalid-run）→ verifies `PRE-002`、`POST-005`、`INV-003`：
  S03 缺对应点；重复次数不足 `5`；S05 非同批；平台矫正未关闭
  （`correct` 非 `False`）；观测量非有限；转译路径违规（转译后电路的
  `CZ` 边集未落入允许集内，允许集 = 子链相邻边 + topo `0–7` 绕行
  `0-10-9-7`；若实测未走 `10-9`，另议换最优 `8` 链）——出现任一情况
  相关点判 invalid，不得出图 / 入库。
