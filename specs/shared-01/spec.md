# Feature: shared-01 精确基态公共数据

> 本 spec 分为两部分：
>
> - **Part I — Scientific Description**：说明科学目标、实验 / 计算定义与输出，面向研究者阅读。
> - **Part II — Specification Contract**：定义边界、前置条件、结果条件、不变量与验证要求，作为可检查的规范性约束。
>
> 两部分必须一致；若存在冲突，应先澄清并修正 spec。

## Part I — Scientific Description

### 1. Objective

为 `exp01`（有限尺寸相图）与 `exp02`（拓扑物理量）提供公共输入数据：
在 `L=8` 参数网格上求解精确基态（S01），并给出三相代表点基态（S02）。
本 feature 只生产基态数据，不作任何观测量计算与成图。

不要在这里写实现方案或验收细节（见 Part II）。

### 2. Experiment / Computation Definition

- 系统 / 模型：SSH XXZ 链，`L=8`，OBC，格点编号 `1,…,8`，
  哈密顿量 `H(s,δ)` 定义见 `doc/theory/H.md`（`H = Ho + He`，
  `h_kl = e^{-δ}(XkXl + YkYl) + e^{+δ}ZkZl`，`PRE-001`）。
- 求解扇区：直接对角化全空间 `H(s,δ)`（`2^8 = 256` 维），取最低本征态为基态；
  不使用对称性惩罚 `H'`，不限制在 `P=-2` 扇区（`PRE-004`）。
- 参数网格（S01，`PRE-002`）：横坐标为 `s`，纵坐标为 `δ`；
  `s = i/100`（`i = 1,…,99`），`δ = j/50`（`j = 1,…,99`），
  即 `s ∈ [0,1]`、`δ ∈ [0,2]` 各取 101 点均匀划分后去掉边界，
  共 `99 × 99 = 9801` 个点。
- 代表点（S02，为 S01 网格的子集，共 3 点，`PRE-003`）：
  - 平庸相：网格最左下点 `(s,δ) = (0.01, 0.02)`；
  - 拓扑相：网格最右下点 `(s,δ) = (0.99, 0.02)`；
  - AFM 相：中间列最上行 `(s,δ) = (0.50, 1.98)`。
- 数值设置：稠密全对角化（256 维，数值精确至双精度求解器极限）；
  不引入截断、对称性投影或近似。
- 流程：对每个网格点构造 `H(s,δ)` → 全对角化 → 记录最低本征对；
  S02 三点无需独立计算，从 S01 结果中标识即可（一致性要求两者同一，
  `POST-002`）。

### 3. Outputs

- S01：每个网格点的完整基态波函数振幅（256 分量，计算基矢约定随数据一并记录）
  与基态能量 `E0`，附参数元数据 `(s,δ,L)`（`POST-001`）。
- S02：三个代表点各自的基态波函数振幅与基态能量，附参数元数据与相标签
  （trivial / topo / AFM，`POST-002`）。
- 具体落盘格式与存储路径由 plan 确定；须保证 exp01、exp02 可按 `(s,δ)` 检索
  （`POST-003`）。

本节说明输出的科学含义；精确的约束与验收条件写入 Part II。

## Part II — Specification Contract

本部分只记录具有规范性、可检查意义的约束。每条独立约束使用稳定 ID。

### A. Boundary

#### In Scope

- `BND-001` S01：`L=8` 网格上每个 `(s,δ)` 点的基态波函数与基态能量。
- `BND-002` S02：三个代表点（S01 网格的子集）的基态波函数与基态能量。

#### Out of Scope

- `BND-003` 由基态计算 `S(q)`、`S(π)`、string、`Q`、`~Z_R` 等观测量（exp02）。
- `BND-004` 相图与热力图绘制（exp01、exp02）。
- `BND-005` 能隙标度 `L=12,16` 计算（exp03 自含）。
- `BND-006` 任何 VQE、真机测量与读出缓解（exp04–exp06）。

#### Dependencies

- `DEP-001` 无外部数据依赖（自含；模型定义见 `doc/theory/H.md`）。

### B. Notation

只定义本 feature 特有且理解 Contract 所必需的符号。

- S01：`99×99` 网格基态数据集（每点 `ψ0`、`E0`，附 `E1` 供简并判定）。
- S02：三相代表点基态（S01 网格子集，附相标签）。
- 简并标记：`E1 − E0 < 1e-8` 的点记入 manifest 简并点表。

### C. Preconditions

定义合法计算开始前必须成立的条件。

- `PRE-001` 系统：SSH XXZ 链，`L=8`，OBC，格点编号 `1,…,8`；
  `H(s,δ)` 定义见 `doc/theory/H.md`。
- `PRE-002` 参数网格：`s = i/100`（`i = 1,…,99`），`δ = j/50`
  （`j = 1,…,99`）；各取 101 点均匀划分后去掉边界，共 `9801` 点。
- `PRE-003` 代表点：平庸相 `(0.01, 0.02)`、拓扑相 `(0.99, 0.02)`、
  AFM 相 `(0.50, 1.98)`；S02 三点不独立计算，从 S01 同坐标条目标识。
- `PRE-004` 求解方式：直接对角化全空间 `H`（256 维）取最低本征态；
  不使用对称性惩罚 `H'`，不限制扇区；不引入截断、对称性投影或近似。

### D. Postconditions

定义一次成功计算完成后必须成立的条件。

- `POST-001` S01：每个网格点的完整基态波函数振幅（256 分量，
  计算基矢约定随数据一并记录）与基态能量 `E0`，附参数元数据 `(s,δ,L)`。
- `POST-002` S02：三个代表点各自的基态波函数振幅与基态能量，
  附参数元数据与相标签；与 S01 同坐标点数据一致。
- `POST-003` 具体落盘格式与存储路径由 plan 确定；
  须保证 exp01、exp02 可按 `(s,δ)` 检索。

### E. Invariants

定义在指定计算区间或状态内始终必须成立的条件。

- `INV-001` `H` 厄米；本征对满足本征方程至求解器数值精度。
- `INV-002` 简并记录：若某点最低两本征值差在求解器数值精度内不可分辨
  （基态简并或近简并，阈值 `E1 − E0 < 1e-8`），不得静默挑选其中之一——
  须记录该点的简并情况，并保留求解器返回的最低本征矢，交由下游实验解释。

### F. Validation

定义如何判断结果满足本 spec。Validation 引用其验证的 Contract ID，
而不是重新定义对应约束。

- `VAL-001` → verifies `POST-001`、`POST-003`：输出形状恰为 `99×99` 点，
  坐标与 `PRE-002` 定义逐点一致。
- `VAL-002` → verifies `INV-001`：`H` 厄米；每点本征残差
  `‖Hψ0 − E0ψ0‖ / max(1, ‖H‖) < 1e-8`。
- `VAL-003` → verifies `POST-002`：S02 三点条目与 S01 同坐标条目一致。
- `VAL-004` → verifies `INV-002`：凡 `E1 − E0 < 1e-8` 的点必须出现在
  manifest 简并点表中，且保留求解器返回的最低本征矢（抽查断言）。
- `VAL-005`（诊断，只记录）：最左列与 `s = 0` 奇键单态乘积的重叠
  （定性一致性检查，阈值由 exp01 / exp02 解释，本 feature 不设）；
  与 v0.2.0 同物理定义在抽样点的 `E0` 交叉比对（实现正确性参照）。
- `VAL-006`（invalid-run）→ verifies `INV-002`：基态简并或近简并而静默挑选
  其中之一（未记录简并情况或未保留最低本征矢）——出现即相关点判 invalid，
  不得静默入库。
