# Feature: shared-01 精确基态公共数据

## 1. 目标

为 `exp01`（有限尺寸相图）与 `exp02`（拓扑物理量）提供公共输入数据：
在 `L=8` 参数网格上求解精确基态（S01），并给出三相代表点基态（S02）。
本 feature 只生产基态数据，不作任何观测量计算与成图。

## 2. 边界

负责：

- S01：`L=8` 网格上每个 `(s,δ)` 点的基态波函数与基态能量。
- S02：三个代表点（S01 网格的子集）的基态波函数与基态能量。

不负责：

- 由基态计算 `S(q)`、`S(π)`、string、`Q`、`~Z_R` 等观测量（exp02）。
- 相图与热力图绘制（exp01、exp02）。
- 能隙标度 `L=12,16` 计算（exp03 自含）。
- 任何 VQE、真机测量与读出缓解（exp04–exp06）。

依赖：

- 无外部数据依赖（自含；模型定义见 `doc/theory/H.md`）。

## 3. 实验 / 计算定义

- 系统 / 模型：SSH XXZ 链，`L=8`，OBC，格点编号 `1,…,8`，
  哈密顿量 `H(s,δ)` 定义见 `doc/theory/H.md`（`H = Ho + He`，
  `h_kl = e^{-δ}(XkXl + YkYl) + e^{+δ}ZkZl`）。
- 求解扇区：直接对角化全空间 `H(s,δ)`（`2^8 = 256` 维），取最低本征态为基态；
  不使用对称性惩罚 `H'`，不限制在 `P=-2` 扇区。
- 参数网格（S01）：横坐标为 `s`，纵坐标为 `δ`；
  `s = i/100`（`i = 1,…,99`），`δ = j/50`（`j = 1,…,99`），
  即 `s ∈ [0,1]`、`δ ∈ [0,2]` 各取 101 点均匀划分后去掉边界，
  共 `99 × 99 = 9801` 个点。
- 代表点（S02，为 S01 网格的子集，共 3 点）：
  - 平庸相：网格最左下点 `(s,δ) = (0.01, 0.02)`；
  - 拓扑相：网格最右下点 `(s,δ) = (0.99, 0.02)`；
  - AFM 相：中间列最上行 `(s,δ) = (0.50, 1.98)`。
- 数值设置：稠密全对角化（256 维，数值精确至双精度求解器极限）；
  不引入截断、对称性投影或近似。
- 流程：对每个网格点构造 `H(s,δ)` → 全对角化 → 记录最低本征对；
  S02 三点无需独立计算，从 S01 结果中标识即可（一致性要求两者同一）。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- S01：每个网格点的完整基态波函数振幅（256 分量，计算基矢约定随数据一并记录）
  与基态能量 `E0`，附参数元数据 `(s,δ,L)`。
- S02：三个代表点各自的基态波函数振幅与基态能量，附参数元数据与相标签
 （trivial / topo / AFM）。
- 具体落盘格式与存储路径由 plan 确定；须保证 exp01、exp02 可按 `(s,δ)` 检索。

## 5. 验证

- 正确性条件：`H` 厄米；本征对满足本征方程至求解器数值精度；
  S02 三点数据与 S01 同坐标点数据一致。
- 收敛 / 稳定性要求：全对角化无截断，不适用迭代收敛判据；
  数值精度以双精度求解器极限为准。
- 参考解 / benchmark：`s = 0` 处基态为奇键单态乘积（见 `doc/theory/psi0.md`），
  网格最左列（`s = 0.01`）结果须与其连续可比（定性一致性检查，归 exp01/exp02 解释）。
- invalid run 判据：若某点最低两本征值差在求解器数值精度内不可分辨
  （基态简并或近简并），不得静默挑选其中之一——须记录该点的简并情况，
  并保留求解器返回的最低本征矢，交由下游实验解释。
