# Design

## Context

- 现状：存档含全网格基态；`S(π)` 热力图已用归一列；三线形状已在探索阶段用存档验证。见 `proposal.md` 动机。
- 约束：`operator.md` 不动；纯后处理；标题去边界条件规则沿用。

## Goals / Non-Goals

**Goals:**

- 一张图同时论证 π 取值的合理性与 S(q) 不足以分平庸/SPT。

**Non-Goals:**

- 不动存档、求解、既有派生与热力图；不引入新依赖；不在文档加注记。

## Decisions

### 1. q 密采样而非 PBC 量子化动量

`q∈[0,2π]` 取约 200 点连续曲线。OBC 下动量没有 `2πk/L` 量子化，只画 8 个离散点会借用 PBC 语言、引来疑问；连续曲线还能显示峰形（针状 vs 宽包），正是本图要讲的故事。

### 2. 纵轴用归一 S̃(q)

与 S̃ 热力图同语言（峰顶 1）；原始峰值 8 在图注/caption 文字中说明，不另立坐标。

### 3. 取点用实测格点

平庸/SPT 取 δ=0 切片的 `(0,0)`、`(1,0)`；AFM 取 `S(π)` 实测最大值所在存档格点（当前为 `(≈0.58,3.0)`），取点逻辑按"峰值格点"声明而非写死坐标，以免网格变更后失据。

## Risks / Trade-offs

- [Risk] 平庸/SPT 两线重合被误读为画重 → Mitigation：图例 + caption 写明"两者均为 O(1) 宽包、峰值约 0.25"，把重合本身讲成结论。
- [Trade-off] 密采样 200 点 × 3 行 Fourier 求和为秒级，无性能顾虑。
