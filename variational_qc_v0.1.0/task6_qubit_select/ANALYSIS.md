# task6 真机 8 比特选链结果分析

745 条物理链（Baihua 244 + Shenglian 501）真机基准全收回。原始数据：
`data/task6_qubit_select_recommendation.json`（745 条全量 evidence）；
本文件是人话版结论。

## 结论先行

后续真机实验用 **Baihua `[67, 68, 69, 70, 71, 72, 73, 74]`**，
score 0.7686（稳定子均值 0.7649，读出保真度 0.7832）。

诚实注脚：与第二名 `[68, 69, 70, 71, 72, 73, 74, 75]`（0.7534）分差仅
0.0151 < 0.02，按规则视为**并列**——两窗口重叠 7 比特，属同一物理区域，
选哪边都一样。

Top 3（外加第三名 `[69..76]`，0.7479）的并集是 **67–76 这 10 个比特**，
三条链分数梯度平滑（0.77 → 0.75 → 0.75）无断崖——整片邻域健康，
后续真机实验认准这片：8 链取 `[67..74]`，换花样也在 67–76 里打转。

## 好链聚簇

- Baihua 好链集中在两个区域：**67–76**（前三名全在这，外加 `[67..73, 86]`）
  和 **126–153**（第 5、6、8、9、10 名）。
- Shenglian 好链在 **55–82** 一带，前五名全由 55/60/61/66/67/68/75/82
  这组比特的不同走法构成。

## 稳定子–读出相关性：权重的事后验证

- Shenglian 相关系数 **0.93**：读出和门一起坏，均匀退化。
- Baihua 相关系数 **0.62**：分化明显——存在读出尚可但门差的链，
  只看读出会选错。打分权重 `0.8·稳定子 + 0.2·读出`（双比特门优先）
  在 Baihua 上是必要的，不是拍脑袋。

## 基准电路（每条链跑满 4 个）

逻辑比特 0..7 按链顺序映射到 `target_qubits`，`coupling_map=[[0,1],…]`
把线性拓扑 pin 死，转译不许绕路——测的就是这条链本身。

- **制备**：全 H + CZ 链 `CZ(i,i+1), i=0..6`，共 7 个 CZ，得线性 cluster 态。
  转译后 7 个 CZ 一一保留（以 Baihua 冠军链为例，落在物理比特
  128/129/142/141/140/139/138/137 上），优化器未吃掉任何一个。
- **`stab_g0` / `stab_g1`**：同制备 + 按 qubitwise 分组加单比特 `Rx/Ry`
  转基矢（旋转角与 estimator 共用 `PAULI_ROTATIONS` 表），Z 基测量。
  8 个稳定子天然分成奇偶两组：偶组 `<S_0>,<S_2>,<S_4>,<S_6>`，
  奇组 `<S_1>,<S_3>,<S_5>,<S_7>`，其中 `S_i = Z_{i-1} X_i Z_{i+1}`，
  端点 `S_0 = X_0 Z_1`、`S_7 = Z_6 X_7`。测量段无纠缠门是设计使然。
- **`allzero` / `allone`**：裸测量 / 全 X 后测量，无 CZ（intentionally），
  `P(00000000)` 与 `P(11111111)` 平均得读出保真度。
- **打分**：`0.8 × mean(<S_i>) + 0.2 × readout_fid`，稳定子探 CZ 门质量，
  读出只占辅助位。
- **可信度自检**：若 CZ 未真实执行，稳定子应 ~1.0；实测冠军 0.76、
  烂链 0.1–0.5，按链质量单调退化的噪声谱即硬件执行的签名。

## 方法回看- 无向去重（`min(链, 反转)`）砍掉约一半重复提交，旧 survivors 反向孪生率

- 静态预筛（边保真度 `< 0.9`）只在 Baihua 砍掉 10 条，Shenglian 零砍掉——
  sample 已按静态边保真度排序截断，预筛更多是卫生过滤。
- 事故：提速重启时 resume 语义错误，重提了 2573 个旧任务；360 个 pending
  中的被 cancel+delete 追回，其余已执行的机时无法追回。runner 已修复为
  "有 tid 只轮询不重提"。

  导致单条掉队任务空转——靠 query Failed 状态发现后单条重跑收回。
  qmeas 轮询器待加固（Failed 自动对账），留给后续 change。
