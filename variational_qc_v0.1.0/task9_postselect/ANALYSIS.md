# task9 真机后选择（A+B）结果分析

对 task8 612 checkpoints 纯后处理，零机时。原始产物：
`data/interim/`（E/Q/OS/retention CSV）与 `data/figures/{min,q,full,os}/`（20 张）。

## 结论先行

- **方案 A（M=0 洗 O/S/Q）**：左支（s<0.6）Q 几乎贴回解析线 1.0，
  右支没救回来（滞留 ~+1 而非 −1）——M=0 筛留下了平庸分支成分，
  SPT 分支的 Q=−1 在噪声下不可恢复。后选择能洗噪声，不能创新物理。
- **方案 B（H_post）**：形状与裸 E 一致、整体略下移，诊断量成立；
  变分上界仍看裸 E。
- **保留率即诊断**：Z 基 M=0 保留率 triv/afm ~0.5–0.7，
  **topo 仅 ~0.18**——0-7 长程单态经桥 SWAP 后对称性泄漏最严重，
  桥的代价直接体现在这里。

## Q 超界说明

后选择 Q 在右支超过 +1（最大 1.54）：Q 的 ±1 校准只对两相基态成立，
M=0 子系综的 O/S 组合可出界，属合法值；画布纵轴已放宽到 ±1.7，
非绘图 bug。

## 修正：后选择不适合做相指示器

- **M=0 筛子是相盲的**：两相基态都住在 M=0 里，过滤不选相、只选扇区。
  噪声主导时 M=0 子集被压向对称点（O→0，S→~0.16，Q→~+1.1），
  右支滞留 +1 而非 −1——相区分度是被过滤器本身吃掉的，不是算错。
- **裸 Q 反而更能反映拓扑分区**：M≠0 的泄漏串里还带着相的信息
  （阻尼偏的方式两相不一样），1→−1 台阶在，毛刺认了。
- **后选择的正确位置是诊断**：保留率表（桥代价实锤）与
  "对称性破缺占 40%" 的分解是它的价值；不当相证据，不当上界。

## 方法回看

- 空集：零 NaN（最低保留率 9.3%，1024 shots 下 M=0 子集仍 ~95 shots，
  可用）。
- Q 由分量复算 assert 全过（1e-9），合成自洽。
- ZR 不在范围（需 tomography，无数据）。
