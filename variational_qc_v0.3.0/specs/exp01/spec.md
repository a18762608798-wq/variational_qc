# Feature: exp01 有限尺寸相图

## 1. 目标

由 S01（`L=8` 参数网格基态）计算归一化拓扑反映量 `~Z_R` 网格，
产出 D01（数据集 + 无标记相图裸图），并以 D01 裸图为底图叠加三对起点 /
终点标记与演化方向箭头，得起点终点标记示意图（D05）。
本 feature 只生产 D01、D05，不负责相图之外的任何观测量与实验。

## 2. 边界

负责：

- D01：S01 网格上每点的 `~Z_R` 值（与 S01 同网格、`99×99` 点），含数据集与无标记相图裸图。
- D05：D01 裸图底图 + 三对标记与配对箭头叠加（见 §3）。

不负责：

- S01 基态生产（shared-01，保持开放引用，不封盘）。
- `S(q)`、`S(π)`、string、`Q` 热力图（exp02）。
- 能隙标度（exp03 自含 `L=8,12,16`）。
- VQE、真机测量与读出缓解（exp04–exp06）。
- 拟设结构示意图 D06（exp04，纯示意，无数据依赖）。

依赖：

- S01：`data/shared01/`（schema `shared01/v1`），基态波函数 + 能量 + 简并点表。

## 3. 实验 / 计算定义

- 输入：S01 网格每点的基态波函数 `ψ0`（`256` 分量，基矢约定见 S01 manifest）。
- 子系统取法（见 `doc/theory/topological_op.md`）：`L=8` 取中间 `2n=4` 格点为 `I`
  （即格点 `3,4,5,6`），左右连续块 `I1=(3,4)`、`I2=(5,6)` 各 `n=2` 比特；
  `R_I` 为中央键镜像交换。
- 观测量：`Z_R = Tr(ρ_I R_I)`，`~Z_R = Z_R / sqrt([Tr(ρ_I1^2) + Tr(ρ_I2^2)] / 2)`，
  其中 `ρ_I` 为 `ψ0` 在 `I` 上的约化密度矩阵，`ρ_I1`、`ρ_I2` 类推。
- 网格：与 S01 同网格（`s = i/100`、`δ = j/50`，`i,j = 1,…,99`），逐点计算，
  不插值、不平滑。
- 简并点处理：对 S01 manifest 简并点表中 `404` 点不做特殊处理，统一使用
  S01 存储的 `ψ0` 计算（S01 规则：保留求解器最低本征矢，交下游解释）；
  D01 数据集须逐点携带简并标记（继承自 S01），以便下游判断。
- 标记：三对起点 / 终点，每对同相，配对固定——
  平庸对 `(0.01,0.02) → (0.21,0.42)`（`~Z_R ≈ 0.996`）、
  拓扑对 `(0.99,0.02) → (0.90,0.20)`（`~Z_R ≈ −0.98`）、
  AFM 对 `(0.50,1.98) → (0.61,1.44)`（`~Z_R ≈ 0.009`）；
  终点均为 D01 落定后在其起点同相连通区相深处选取的网格点。
  三对各用一色区分；起点沿用圆点样式三色；终点 marker 形状与颜色均区别于起点；
  每对起点→终点画演化方向箭头。
- D05 由 D01 裸图叠加上述标记与箭头得到；出图实现本身由实现层安排，不属实验定义。

只有影响实验语义、结果解释或可重复性的内容才写入这里。

## 4. 输出

- D01：`~Z_R[99,99]`（与 S01 同坐标 ordering），附参数元数据 `(s,δ,L)`；
  无标记相图裸图（与数据集同坐标系）。
- D05：D01 裸图底图 + 三对标记与配对箭头叠加；三对坐标与配对关系、颜色区分存档。
- 来源标注：输入 S01 的 schema（`shared01/v1`）与 manifest 标识；每点简并标记。
- 具体落盘格式与存储路径由 plan 确定；须保证出图可按 `(s,δ)` 检索。

## 5. 验证

- 正确性条件：每点 `ρ_I` 迹为 `1`、厄米半正定；归一化分母非零有限；
  D01 无缺失、无 NaN；网格坐标与 S01 逐点一致。
- 收敛 / 稳定性要求：本 feature 无迭代求解，不适用收敛判据；
  数值精度以双精度计算极限为准（具体阈值由 plan 定）。
- 参考解 / benchmark：`δ` 大（Ising 偏）区与 `s→0` 区 `~Z_R` 的定性行为
  由相图解释，归下游判断，本 feature 只保证计算正确性。
- invalid run 判据：S01 输入缺失或 schema 不符；任一点 `ρ_I` 迹偏离 `1`
  超出 plan 定阈值；简并标记丢失；D05 底图与 D01 坐标系不一致；
  D05 标记坐标/配对与 §3 不符——出现任一情况该点（或整批）判 invalid，
  不得静默出图。
